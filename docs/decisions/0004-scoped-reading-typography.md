# ADR-0004：增加受控长文阅读角色，不放大全站操作字号

## 状态

Accepted（仅新增角色与本轮E02样板；不改变既有Shell/14px操作正文，不代表50页或真实科研能力验收）。

## 日期与依据

2026-10-20。用户在UI/UE审查后明确要求修改文档或页面并进行新的浏览器实测，以实际动作收口规则。

## 决策

- 既有Foundation字号、导航和布局数值保持；追加Reading正文角色16px/28px、400字重，使用有意义的独立Token。
- 仅论文连续正文与对应解读段落显式采用；表单、按钮、数据操作仍14px/22px，元数据保持12/13px。不能将阅读字号全局套给所有p/输入/表格。
- 阅读区域控制可读行宽，自然增高与折行；窄工作区/放大状态优先重排，不缩字。辅助栏不作为第二个全文区域。
- 本轮用E02多个桌面视口、连续正文和解读抽屉进行前后截图及computed实测；变体后续推广仍逐页登记，不自动宣称全站达标。
- 同步Foundation至V1.1及实施规则，保留原文件路径以免断开历史引用；新增Token不改旧值，只有显式消费者产生视觉变化。

## 取舍

全站改为16px会改变密集采集/列表的既有布局，不采用；继续让13/14px兼任长文不利于持续阅读，因此增加独立角色。具体专业可用性仍须用户评审，自动化不替代专业验收。
