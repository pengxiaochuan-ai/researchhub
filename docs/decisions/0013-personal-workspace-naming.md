# ADR-0013：个人入口统一称为“我的工作台”

状态：Accepted，2026-11-17用户明确要求实施。

客户所称专家工作台对应现有个人工作空间，承载知识、课题、任务、日程和产出。将原“我的科研”显示名统一为“我的工作台”，使导航、浏览器标题、登录及返回提示和帮助说明一致。

五个一级入口仍按原位置和顺序排列，仅首项改名；p01及所有URL、API、存储键、权限、组件布局、字号与人名问候不变。不增加另一个专家工作台，不改变个人/课题私有边界。旧文档中的原名称作为历史保留，现行名称以本ADR和本轮产品基线为准。

对比已捕获的双角色五宽页面、原生200%及实际跳转，运行受影响单元/集成、生产构建并保存截图视频。本机验证不等同生产发布。

规格：[统一命名](../product/my-workspace-naming-2026-11-17.md)。
