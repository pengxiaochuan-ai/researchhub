# ADR-0015 · 独立数据库先交付演示，合库延后

状态：Accepted（交付策略，用户2026-11-19明确确认）；目标资源、权限和真实发布仍按准确清单确认。

## 背景

Hub开发库独立复制，生产aisci从未安装Hub结构。共享库首装需要共享public兼容、迁移权威和旧消费者隔离验证，用户要求优先客户交付，合库放到12月以后。

## 决策

1. 当前将既有Hub开发成果以独立数据库交付为演示验收环境；用户明确允许保留获准资料及合成样例，必须保留合成和来源/审核/用途标识。
2. 暂停共享库首装I01–I06作为当前主线，保留方案与证据；合库列MB-01，12月以后重新评估，不自动开工。
3. 最大复用当前数据结构、数据/文件及独立运行包，先验证一致性快照、独立恢复、amd64与实际业务能力，不清源数据、不碰生产aisci。
4. 不因独立库或演示标签扩大用途、重新执行历史任务、授额/付费或发邮件；不因同机部署操作旧系统和官网。
5. 独立逻辑库可在现有资源上部署，不等于新购云实例。用户随后选择现有RDS中新建独立库；目标角色/库/存储及发布准确清单另核，不采用同机新增PG容器。

## 影响

当前独立交付见[实施边界](../technical/independent-demo-delivery-2026-11-19.md)；共享库[首装方案](../technical/hub-first-install-production-plan-2026-11-19.md)成为延期参考，非本次发布前置。部署成功与客户业务验收分开，未来合库不得覆盖客户独立运行后新增的数据。
