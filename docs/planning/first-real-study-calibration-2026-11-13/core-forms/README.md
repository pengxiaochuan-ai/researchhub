本包不将总分直接用于中医主标签、自动诊断或本队列最佳切点；手册严重度区间只留来源记录。第9项保留原文并计入总分，其阳性处理应按医院/研究方案，不由本包虚构风险阈值或响应时限。功能题是否必填/跳题是待审核流程，当前候选为非必填且可单独保留。

## 五主症证据边界

胡随瑜等《抑郁症肝郁气滞证证候标准第一轮专家问卷分析》，中国中医基础医学杂志2002;8(12):21–23，[作者学术门户摘要](https://www.paper.edu.cn/scholar/paper/husuiyu-8)，可支持五项指标线索：情绪抑郁、善叹息、胸胁乳房和/或少腹胀痛、焦虑不安、脉弦。网页第三项有“和P或”的转写瑕疵，显示名的“和/或”仅为便于阅读的解释，不当作已核对论文原文。

摘要中的专家重要性评分不能用作患者计分。本研究用户指定“情绪抑郁必备，另具备2项，总分>4”保留为未完成定义；不得自动假定每项1分/0–3分、另2项为至少/恰好，或把>4改成≥4。文献五项与用户五项尚未确认同一规则，候选表不接收患者数据，也不输出合计/阳性阴性。

学会2025年《抑郁障碍治未病干预指南》[公示通知](https://www.cacm.org.cn/2025/03/08/31399/)所附公示稿第11页规则是另一套症状组合与病程条件，并非用户的五症加权公式；它只作排除混用证据，不是正式2023量表。
