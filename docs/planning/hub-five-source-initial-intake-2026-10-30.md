# Hub 五份具名初始资料入库最小实施规格

日期：2026-10-30。状态：按用户本轮指令实施，仅用于本机专用合成 PostgreSQL；不触及临床库、旧服务、云资源或真实发布。

## 目标与已确认口径

用户将两条 ChiCTR 注册记录、两份针灸研究数据团体标准及一份抑郁症临床实践指南选为首批初始数据，要求先入库并建立后续页面可复用的表结构。ChiCTR2300077209 纳入 Hub 的“情志病相关临床试验”主题，但其原始注册目标疾病必须保留为“轻度认知障碍”，不得计入抑郁症目标疾病子集。五份资料的主题/内容适合作首批开发样本，是用户作出的范围决定；**不冒充 Hub 管理员已具名完成每一项来源权利、字段、用途审核**。

本轮目标是 5 个来源项目、5 个不可变版本及受控原始文件在专用合成库落地；重跑幂等、跨租户不可见。后续页面可基于库中的真实来源元数据与版本开发，不再依赖前端演示常量。公开页与 AI 仍只读取具名管理员日后批准的字段/用途；本轮不自动生成放行事件、不开新权限、不接付费模型。

## 最小物理模型

沿用已有 `rh_source.source_registry`，只新增 ResearchHub 自有对象，不改既有表/旧代码：

| 对象 | 责任与关键字段 | 约束 |
| --- | --- | --- |
| `rh_source.external_document` | 租户、Hub、来源、类型（`clinical_registry`/`research_standard`/`clinical_guideline`）、外部稳定编号、题名、原始目标疾病、Hub 主题纳入决定与依据 | 同租户/Hub/类型/编号唯一；原始疾病与主题标签分开；租户复合外键、强制 RLS。 |
| `rh_source.external_document_version` | 文档 ID、版本序号、SHA-256、原文件名/MIME、来源 URL、来源更新时间、采集时间、结构化事实 JSONB、导入操作者标识 | 同文档 hash/版本唯一，插入后不可覆盖；仅放已核对字段，不复制注册页的联系人直接联系方式到结构化元数据。 |
| `rh_source.external_document_payload` | 版本 ID、原始文件 `bytea` 与字节数，作内部可回查证据 | 强制 RLS；不给应用角色原文读取授权，不开文件下载 API。 |
| `rh_source.external_review_decision` | 版本、字段类别、用途、受众、批准/撤回、具名管理员、权利依据、时间/有效期 | 追加式；本轮不插批准行，也不授予应用角色写权限。后续具名审核接口必须先完成服务端授权与当前版本校验，再单独取得最小写权限；页面/AI 只有在当前决定有效时才可交付对应字段。 |

来源条款、授权和内容审核不能由“用户提供文件”“内部开发样本”或 `source_registry.rights_status=unknown` 自动推断。管理员在三种新类型的导入/审核界面接通后具名登记，方可正式放行。PDF 的完整字节只保存在受控合成库证据表，不生成公开 URL，不嵌入前端包或 AI 向量索引。

## 实施顺序与验收

1. 增量 SQL 与合成目标守门：仅在 `wp01_test_full_baseline`，先核查数据库标记、租户、Hub 与既有 `source.review` 授权；新表全部启用并强制 RLS，应用账号无 payload 读取权。`node --test` 校验表结构，失败不得写入。
2. 固定五份本地文件清单：文件路径、类型、外部编号、题名、来源 URL、入选依据、版本字段及 SHA-256 与本地原件一致；任何缺失/变更使整批失败，不隐式网络抓取。导入事务一次插入 5 项/5 版本/5 份受控原件，重跑逐项核对 provenance 后才报告幂等；不创建任何批准事件。
3. 真实合成 PG 验证：五项/五版本/五 payload 的数量及哈希一致，重复执行结果相同；应用角色跨租户看不到，且不能读取 payload；审核决定为零，公开/AI 仍不会因为资料已入库而自动可见。
4. 同步产品/数据库/测试文档；若后续接页面，管理端先提供具名审核和内部预览，科研端只从当前可用授权投影读取，浏览器验证不得以静态演示数据或数据库行数冒充已公开内容。

独立评审补强：已有同名表不能仅凭表名认定可用；建表脚本须核对关键列、主键/唯一键/复合外键、RLS 和应用角色有效权限（含列级授权），任何漂移失败关闭，不自动改写旧表。重复导入须核对来源 URL、入选依据、版本号、来源更新时间与导入身份等 provenance 字段。

本轮完成条件只覆盖“代码已实现＋专用合成环境已配置＋真实入库/查询执行”。没有管理员具名权利决定与页面/AI 专业验收时，不宣称“已公开展示”“AI 已检索”或“业务验收通过”。
