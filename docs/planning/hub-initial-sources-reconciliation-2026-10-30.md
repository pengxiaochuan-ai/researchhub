# Research Hub V1.1 数据规范差异清单与首批来源顺序（评审稿）

日期：2026-10-30。状态：**Proposed，仅用于讨论与排期，不授权外部采集、批量发布、付费调用、数据库迁移或真实部署**。

执行补记：用户另行批准五份具名文件作为内部初始数据入专用合成库，并建立最小独立来源/版本/原文件/审核决定表。这项明确授权已按[实施规格](hub-five-source-initial-intake-2026-10-30.md)执行；本评审稿其余批量采集、公开/AI 放行和正式审核规则未因此获批。合成库实测 5 文档、5 版本、5 原文件、0 审核决定，重复导入为 0 新增版本。下文“未入库”等表述是执行前快照，以本补记为准。

## 1. 核对基准与结论

本清单逐项对照：

- [`岐研_Research_Hub_V1_后端数据与采集技术实施规范_v1.1.docx`](../product/岐研_Research_Hub_V1_后端数据与采集技术实施规范_v1.1.docx)，重点第 1、3–6、12–19 节；
- [`岐研_Research_Hub_V1.1_数据字典与采集实施表.xlsx`](../product/岐研_Research_Hub_V1.1_数据字典与采集实施表.xlsx)，重点 01/02/03/07/09/10 工作表（45 张建议表、312 个字段、S1–S13 ETL 与 AC-01–AC-16）；
- [已确认的共享 PG 租户边界](../decisions/0003-shared-database-tenant-boundaries.md)、[独立来源目录设计](../superpowers/specs/2026-10-30-hub-source-catalog-design.md)、[现行来源 living spec](../product/hub-source-catalog-spec-2026-10-30.md)、[H0 规格](../product/domain-hub-h0-spec-2026-10-30.md)、[PRD V2](../product/lingshu-product-prd-v2.0.md)。

**结论：v1.1 的逻辑分层和临床注册实体建模值得保留，但它不是可以直接执行的物理 DDL。** 已确认部署是共享 PostgreSQL、共享既有公共表、按租户隔离；现有 `rh_source` 是书目工作簿的隔离暂存与审核切片，不能等同 v1.1 中的通用采集、跨源临床研究实体和全量科研资产模型。先做纵向来源样本和权利核验，再按真实所需最小增量补字典/迁移，不把 45 张建议表一次建完。

## 4. 最小执行关口与交付口径

1. **决策关口**：先确认 Q01–Q04 的具体负责人和依据。对 ChiCTR/ITMCTR 只做公开渠道/条款核验，不触发自动采集；对现有工作簿不代管理员审核。
2. **字典关口**：先出 v1.1→PostgreSQL 的最小字段/约束补丁（租户、来源稳定键、版本、权利、审核、临床 Trial 与指南最小字段），与现有 `rh_source` 的行证据保持兼容。未经评审不迁既有 15,697 行、不触碰旧公共表。
3. **技术关口**：专用合成环境对每个来源跑新旧内容幂等/变更版本、错字段、跨租户、撤审、重复候选、来源回查；界面实测管理→审核/撤回与领域列表→详情→AI 检索。付费模型另按当轮有效报价/累计预算授权。
