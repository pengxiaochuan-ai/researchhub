## 确认、建议与待验证的边界

- **已确认：**上表业务要求、原文档明确的一期范围及C14所指WP01包级技术边界。
- **推荐待审：**包外整体后端受控复用、统一平台运维入口、AI任务契约与具体里程碑；WP01实施计划/方式与唯一共享迁移入口已批准，实际迁移仍另过门槛。
- **待验证：**真实库角色/RLS、后台任务领用隔离、OCR/Embedding/模型/联网/方法 Worker、目标环境与专业效果。
- **需一次性收口的物料/政策：**见准备清单 Q01–Q08；不是重复询问已经确认的租户或主验收链。

## 评审与变更

1. 用户审阅四份材料后，对技术方案和未决项给出一次集中反馈；确认后再拆可执行实现计划。
2. 样例和效果可迭代。每次变更记录来源、改动、受影响能力/测试、对日期的影响及确认人，不覆写原验收标准。
3. 任何已确认核心能力延期、缩减或替换必须明示并再次确认；不能用主线通过掩盖其他 AI 入口未完成。
4. 2026-10-19方案轮仅文档；2026-10-20已进入上文Task 1代码切片。运行库、密钥、部署和迁移未改，文档中的未执行业务门槛不得提前销项。
