## 规则与交互

- 本片处理表单数据列的同名歧义、无法匹配列及多个源列竞争同一目标。身份/访视/研究绑定的结构错误、直接身份信息、公式/重复表头、非法值及单位规则继续原校验，不把选择操作变成绕过异常的入口。
- 自动对应保留并显示在原摘要。待核对列显示“原列 → 表单字段”与明确“不导入此列”；同名目标显示label＋key＋单位区分。未识别的可选列默认不写，待核对的必填字段必须覆盖；同一工作表一列只能对应一个目标，一个目标不能被两列覆盖。
- 选择阶段不写被试/访视/答卷；“核对字段”只准备原导入计划，随后原“确认导入”才写业务对象。原件值/SHA/位置不改，转换由确定性程序处理。选择失败保留输入，可修改后重核；未知准备/确认先查原key，不重复POST。
- 来源/Study/账号改变清空旧选择，迟到响应不回填；页面刷新可重新取得选项，原文件保留。服务端指纹变化拒绝旧选择，明确重新核对，不悄悄套用新表单。
- 原两账号与现有Study权限不扩。本片可建立具名合成上传/预检/映射计划；已固定4份CRF保持。实际业务提交采用独立具名真实PG回滚验证，不新增持久业务对象或改原答卷；目标环境真实HTTP/浏览器验证到固定计划及恢复。
