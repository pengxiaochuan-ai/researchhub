# 岐研 AI 九项默认 Skill · T04 范围修订

2026-11-07 用户明确：所有 Hub 账户默认装备九项 Skill，作为面向医疗科研人员的内置能力。本决定取代 11 月 6 日“仅两账号、最多 18 条装备”的待确认提案，不再逐账号申请。原 T01–T15 的实际执行与专业验收标准不变。

## 实施决定

复用既有 `Skill` 版本及 `SkillAssignment` 的 `accountId=null, scopeKey='*'`，每个 Hub 专属 Agent 九条默认装备即可覆盖现有及未来账号。安装器接收明确的 Hub 租户/Agent/具名管理员，不枚举共享库所有租户，不创建平台官方全局 Skill；同一模块可由后续 Hub 部署初始化复用。公开注册无须修改或额外授予私有 Study 关系。

逐账号复制九条装备不选用：维护成本大且容易遗漏新用户。直接向旧系统所有账号或所有 Agent 开通也不选用：不符合独立 Hub 项目边界。

保持原生发布、版本、装备语义、具名审核及审计；安装在共享租户授权锁内原子完成，身份从当前数据库校验。重复启动不重写发布版本、不恢复管理员显式禁用的默认/账号覆盖，不自动将已变化原包当成已审核新版本。

默认装备不等于获得 Agent 使用权限、其他人的资料、私有 Study 或 Token。停用账号/租户、账号特定禁用、版本失效及资源权限继续约束；不加临床数据、shell、全盘文件、共享、审批、锁库、发布科研产物、导出或充值权限。

## 当前切片与验收

先完成九项固定版本登记、一次具名默认发布/装备，以及读取当前账号有效装备的 Hub 后端接口；管理员与研究者都从同一真库投影读取，注册后没有 Study 的账号亦能读取本人的默认能力目录。不得把登记/装备宣传为九项模型执行已完成。

当前九项执行适配仍在 T05–T13，发布记录显式携带 `pending-runtime`，不加载成旧固定分支 SkillInvoker 的任意指令，不通过静默模型降级冒充实际能力。不修改当前 AgentConfig 的工具/声明集合，避免破坏既有单篇/知识库问答；T05 接线完成再联合切换 `skill.invoke` / 当前授权文档读取与运行版本。

测试：九项/唯一键/固定快照、已有及未来账号继承、账号与默认停用优先、未发布/跨租户/停用身份拒绝、重跑幂等、来源变化拒绝、原子回滚、并发安装防重。专用合成 PG 用具名新夹具演练，不读临床库；当前合成 Hub 安装时核对旧装备、角色、AgentAccess、Study 关系、Token、配置和其他租户均未变化。浏览器回归原布局并验证真实能力目录，新增默认能力不要求重设计页面。
