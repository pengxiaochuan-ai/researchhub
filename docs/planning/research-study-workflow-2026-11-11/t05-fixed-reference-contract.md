# T05 固定发布材料核验

2026-11-11，沿 T04 已固定的 Outcome、FormVersion、ScaleVersion 核验；同一个旧系统 TS 核心供旧服务与 ResearchHub 复用，避免仅新入口守门。

调用方先锁当前正式方案，再传入当前受控事务、租户/组/执行项目与方案。核验所有主要/次要结局的 ID 和版本，以及访视要求的表单/量表固定 ID。旧字符串或 templateKey 不作为已固定版本。结局及表单必须属于同一项目，量表仅允许官方或当前租户及其合法定义；材料仍须发布，表单可为 locked。

对引用版本及父行使用共享行锁，核验可用表单字段、量表题项和已发布确定性算子规则。不能用仅标 published 的空结构或未知计分算子放行。此项不产生受试者记录、不运行计分、不生成阈值，也不代替团队对内容的专业审查。

返回用户可理解的阻断清单；异常或失效来源不会被跳过。单元正反例后，仍需 T05 PG、旧/新 HTTP 及业务路径验证，不把 helper 测试视为审批能力启用。

第一版支持 `data_field`（该访视固定表单中的唯一字段）和 `scale`（该访视固定量表的 total 或已有分量表键）。结局必须明确方案内访视，缺采集字段、错误访视、同名字段多来源、未知来源或虚构分数键均阻断。文件/其他来源需在相应任务提供固定投影契约后扩展，不从自由文字推断。
