## 交付行为

管理员可创建、编辑、分派、关联/解除、独立验收和记录站内提醒；获分派研究者可开始、提交完成说明和选择实际固定答卷证据。Subject 搜索、访视候选与访视内已提交表单均由真实授权接口读取，常规用户不填写内部 ID、版本哈希或请求键。来源显示假名编号、访视名、表单名、修订号；回链严格核对 Study 与固定版本三元组。任务处理不改变访视状态，不扩大来源读取权。旧来源变化或撤权分别显示“已变化/受限”，不暴露失权源摘要和回链。

S08 的普通确认统一使用共享站内弹窗，保留 Esc、取消、键盘焦点恢复和浏览器刷新/关闭的未保存保护。账号变更、authVersion 变化及真实失权清除内存输入；暂时网络错误保留输入。未知结果持久化最小 actor/authVersion/Study/task/action/key 标记，无任务正文；正文仅本页内存保留十五分钟，刷新后仅可 GET 原回执。404 仍保持未知并禁止新写入；200 验证原键、动作、Study 与 task 后重新 GET 当前任务。CAS 冲突保留原输入和原基准，显式核对后操作，无自动覆盖或自动 POST。

## 失败留痕及边界

历史失败 `t10-ui-df69f6a0`、`t10-ui-cb1cfec2`、`t10-ui-ca6d82f5` 原样保留。前两轮未通过固定证据持久化断言；已给异步来源选择增加父级 busy 门禁，避免读取当前修订期间先提交。后一轮暴露账号初始化 checking 被误判为匿名；已将 checking 与真实账号失效分开，重跑完整链通过。全量测试首次发现加载态母版缺少三个基本字段，已恢复原区域，最终 426/426 通过。

390 和原生 200% 顶栏现有全局搜索与身份区域相邻重叠属于冻结 Shell 的已知限制；本包未调整其布局，未以正文不溢出掩盖这一点。正文任务、筛选、关联、状态与恢复可操作。正式产品文档、使用说明、版本、专项测试/API及 Notion 同步由主循环接续本记录；其收口之前仅标记 UI 实现与本机合成验收通过，不单独宣称 T10 全部交付。
