# T13 正式 CRF CSV 导入合同

状态：后端实施准备，尚未启用或验收；不提前修改S09页面。沿用既有Study授权事务、正式表单分配/提交核心及操作回执，导入不会创建第二套答卷或覆盖已提交值。

固定一个已发布FormVersion；CSV首列为 `subject_code,visit_code`，后续列为该版本字段key，下载模板提供用户标签。只接受已建档、已入组、固定访视计划code唯一匹配且该访视要求包含此固定版本的行；不按时间猜访视、不新建被试。每批最多100行、256KiB。旧feature CSV解析只处理feature_key/value且简单按逗号切分，不能承接带引号、多行文本和正式父链，因此本入口单独作严格CSV解码，复用共同表单字段/必填/计分验证，不复用其隐式Number转换。

数值只按明确数字语法解码并检查有限值/整型，boolean仅接受 `true/false`，select仅接受固定选项值；空白为null缺失，0/false原样保留。固定版本字段决定类型，无单位猜测或自动换算；额外列、缺列、重复列、重复被试/访视行、非法引号/列数和未知访视均为明确错误。保留精确行号/字段定位，不静默跳行。

数值保真增量：CSV入口拒绝非零值下溢为0、不安全整数及无法按Number最短十进制表示保留原十进制值的输入。比较会规范化十进制尾0和指数，因此1.2300与1.23等价；超出支持精度的值返回该行字段错误，请研究者核对格式，不自动舍入。该边界不宣称任意精度十进制算术或修改既有现场数据。

预检不写正式分配、响应或修订。计划接口 `POST /research-studies/:id/imports/preview` 接 `{formVersionId,csv}`；返回行定位、规范值、当前目标版本及只读预检hash；有任一行错误不可确认。`POST .../imports` 接 `{requestKey,formVersionId,csv,previewHash}`，同事务重新授权、按project→sorted protocols→sorted subjects→enrollments/visits锁定全部来源，重验同意、方案、表单与当前版本，并比对预检hash；来源变化整批拒绝。只有新分配或尚未录入的空白draft允许初次导入，既有现场草稿或已提交答卷显示冲突，后续更正走既有更正流程。

整批分配、共同writer提交、CSV来源审计、每行固定ref及actor-bound操作回执全成或全回滚。revision.source仍表达`researcher`采集主体，CSV通道/原CSV SHA256/行号与固定ref写入独立不可变导入操作结果和审计；不把导入伪装成H5、不给旧修订补源。结果不保存CSV正文；每行收据必须回链到真实修订。`GET .../imports/receipts/:requestKey`只读，当前身份、动作/研究/源父链/用途许可重验后返本人原批结果；404仍未知，不自动新键重发。未发送CSV仅内存；结果未知时仅最小范围/动作/键标记持久化。
