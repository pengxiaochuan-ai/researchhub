## 失败、边界与交付层级

`csv-encoding-1613b810/failure.json` 原样保留：实际 POST 的 CRLF 被 textarea 延迟 change 转 LF。最小定位证明原解码 state 保留 CRLF，但先前编辑尚未失焦时，异步文件加载后再点击预检触发旧 change，DOM 返回 LF。修复仅比较 textarea 的标准展示换行、忽略无实质变更，不把规范化字符串存入或提交；上表编码和真实多行文本保存反例复验通过。

503、截断响应和十五分钟为明确浏览器故障/时钟注入；授权、数据库、真实 Cookie、CAS、整批回滚、撤回与回执均实际请求。新导入不自动完成访视、不覆盖现有内容；不能以旧批历史值冒充当前答卷。390/200% 顶栏搜索与账号重叠仍属冻结 Shell 既有限制，正文与区域操作可用，本包未重设计全局布局。
