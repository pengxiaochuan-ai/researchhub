# ResearchHub统一会话实施计划

> 执行方式：沿用用户已批准的当前目录串行实施＋单次独立总评审；无需重复选择执行方式。不提交/重置其他本地改动。

目标：落实[已确认规则](../product/session-policy-2026-11-06.md)，12h Cookie/会话、真实活动续期、过期安全回跳、断网不退出及账号失效拒绝。

架构：ResearchHub自有server/auth模块复用旧AuthService登录/身份及现有账号/authVersion/租户校验，不修改旧系统。复用audit_log按随机会话ID保存退出记录，续期/退出锁内检查；不新建表/授权。旧2h无新会话标识凭证要求重新登录，不静默升级。后台GET不续期。正式入口应引用同一模块，当前目标仅本机专用合成环境，不发布。

## 风险检查重点

跨标签退出和迟到续期不能恢复会话；后台轮询不能续期；后端不可用不得伪装401；所有受保护页面合法上下文可回跳，公开目录不强制登录；authVersion和租户状态不信旧JWT。测试/证据不得泄露Cookie或密码，不改真实账号。
