# 来源审核阅读与连续操作：实施计划

> 执行方式：当前目录串行实施＋独立总评审；用户已批准本轮审查六步骤问题的修补，不再重复提请相同范围确认。

**目标**：保持G02总览和审核权限不变，使管理员能定位正文、核对图表与完整性、连续切篇及完成原有一次决定。

**规格依据**：[两篇PMC实测审查](../testing/pmc-two-article-ux-audit-2026-11-02.md)。用户本轮批准四项优先修正及六个步骤全部问题；[来源审核规格](../product/source-review-workspace-spec-2026-11-02.md)的权限、范围和原子提交规则不变。

**实现选择**：复用本机已保存的JATS及旧服务已安装的XML解析器，按需提供只读结构化阅读；React只渲染白名单文本节点，不直接注入原HTML。未选择重新联网抓取/模型改写；不新增表、依赖、角色、放行记录、费用或发布。

## 约束与验收关注

- 新读取接口只接受原具名当前审核员、当前Hub/租户、当前文章版本；重验本机对象键、大小及SHA，不返回内部路径。失效/损坏明确失败，不回退演示正文。
- 原始组件数不是内容完整率。新增清单仅使用已存来源清单/引用；“原文未列出”“已取得”“已列出但未取得”“待核对”区分，PDF缺失不冒称正文缺失；未知组件不臆断用途。
- 正文16/28、表格及操作14/22，保留图片原比例；章节、引用、图表前后定位可键盘操作，旧决定与历史不变。
- 切篇只滚动详情标题，不重置左队列滚动；新选中对象与动作一致。人工刷新/保存后不跳到另一篇；切账号清理正文与迟到响应。
- 长文操作入口复用同一提交函数及单飞状态；不得绕过禁用条件、遮住内容/键盘焦点、添加重复审核表单。

## 小步任务

- [x] R1：先写失败测试，覆盖JATS章节/段落/引用/图表ID、表头跨度、恶意实体/URL和无正文；实现`server/hub-sources/pmc-reading.mjs`的有界纯转换及当前授权读取，测试转绿。
- [x] R2：`pmc-review-service`只增加来源清单字段，`review-controller`增加具名只读`GET pmc-review-articles/:versionId`。真实PG核对两篇、错误身份/失效/哈希，不写原决定；原图片门禁不变。
- [x] R3：`PmcReviewPreview`＋局部阅读组件，提供章节目录、引用及图表双向定位、真实语义表头、摘要/正文/图表/作者附录/PDF分类与技术文件折叠；未知/失败可恢复。单元及SSR用例验证。
- [x] R4：`HubSourceWorkbench`局部修正计数范围、切篇焦点和滚动、当前对象长文操作入口、明确跳过/下一篇文案；合并子功能重复说明，不动G02总览/公共Shell。队列逻辑测试转绿。
- [x] R5：构建与相关回归；真实浏览器重走两篇六步骤，桌面/390/320/原生200%与键盘/迟到响应，截图和录屏；所有原PMC决定前后只读哈希一致。本轮未进行真实文章保存。
- [x] R6：独立总评审、必要修补复测；同步产品基线/变更/版本记录/使用说明、来源规格/API及本机验证记录与Notion。专业体验仍由用户确认。
