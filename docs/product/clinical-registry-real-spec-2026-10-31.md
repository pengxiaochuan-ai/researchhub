## 最小业务契约

- C01 真实模式经 `GET /api/hub-sources/clinical-registries` 读取当前灵枢心域、当前 v1 文件 SHA、最新未过期 `bibliographic/display=approve/public` 的注册来源。仅展示题名、注册编号、原始疾病、来源名称、获准的 HTTPS 来源链接及审核版本；未审核、撤回、换版或读取失败不回退固定研究。该目录是首批具名来源，不冒称全网注册总量或去重研究实体。
- C03 只接受 C01 给出的不可变 `documentId`，经 `GET /api/hub-sources/clinical-registries/:documentId` 重新核对同一公开门禁；非法、未审核、撤回或换版统一不可见。详情不补造摘要、方案、访视、研究者、机构、样本量、招募状态、结局或 AI 解读；来源文件尚未完成受控正文提取。
- C01 原地图、趋势、完整筛选与分页需要经核验的实体/时间/地域字段，本片只显示“尚无可核验数据”而不渲染演示图表。C03 原“查看原始记录”只在有获准 HTTPS 链接时开放，不提供本地原件字节。
- 两页为公开审核内容；匿名只读能力沿现有 E01/E02 公开投影，不新增 grant。Study 数据、关注、收藏、审批、导出、模型调用与费用不变。管理员 G02 审核/撤回仍是唯一放行入口；C01/C03 不写库。

## UI/UE 与验收

- 工作区公共 Shell、五项一级导航和现有字号/颜色 Token 不变。C01 保留列表和到 C03 的详情入口；C03 保留回列表路径。题名折行，操作 14/22，说明不低于 14/22，来源版本作元数据。手机 320/390px 及原生 200% 不得缩字或使主要入口不可达。
- 首次加载、真正空态、筛选无结果、服务失败、不可见详情分别呈现；失败可重试，迟到响应不覆盖新状态。外部链接仅 HTTPS、`noopener noreferrer`。未知或无权 ID 不带出任何旧示例。
- 单元和回滚 PG 验证当前审批/撤销/换版，真实 HTTP 与 Chrome 验证空态、详情 404、列表导航、视口及截图录屏。若管理员仍未作真实权利审核，持久库预计仍为 0 条公开记录；技术接线通过不等于非空业务内容、专业用户验收或生产发布。
