## 范围与责任

仅 `wp01_test_full_baseline` 中已具名导入的五份外部来源、当前灵枢心域 Hub、现有合成管理员账号。管理员对每份文件的**当前版本和 SHA-256**，分别按书目元数据、摘要、全文，以及公开展示、AI 检索两种用途作明确决定，并提供可核验的 HTTPS 权利依据链接。未建立受控依据登记前，`evidence://` 占位引用一律拒绝。系统不推断许可、不自动批准，也不把来源文件内的文字当指令。原始疾病按来源保留：`ChiCTR2300077209` 为轻度认知障碍研究，只是 Hub 范围候选。

决定以只增事件保存；同一版本、字段、用途的最新决定生效。管理员可撤回已经批准的组合；并发提交须携带预期决定版本，冲突提示刷新。新文件版本必须重新审核。撤销与账号/授权变更在提交事务中重验，失效请求不写入。原文件字节不授予应用角色读取，页面仅显示元数据与指纹，不在浏览器下载原件。

五份对象以租户、Hub、不可变文档 ID、来源类型及外部编号共同限定；相同标签的第六份不在本轮审核范围。受支持的来源版本导入与审核提交对同一文档取相同事务锁。初始五份重新导入和常态验证允许已有合法审核历史，不把“决定数必须为零”当不变量；验证必须核对其归属、当前版本与具名审核人。三份 PDF 无 HTTPS 来源链接，管理员应对照受控离线原件文件名与 SHA-256 核对内容和权利，不能只凭 G02 卡片批准。

V0.1 先交付**审核决定与可追溯状态**，不把仅有决定的资料自动加入现有工作簿论文投影。摘要、全文仍缺受控提取文本及发布/检索投影；相关权利决定可以记录，但不可据此宣称这些正文已经可展示或可供 AI 检索。V0.2 接线必须同时满足：当前固定首版、当前决定、字段有真实可核对内容、对应用途许可和现有 Hub/Agent 授权；缺任一项一律不交付。两条临床注册与三份标准/指南也不冒充论文。

## V0.2：条件式元数据投影（2026-10-31 确认继续）

仅对上述五份具名外部对象提供独立、只读的“临床注册 / 研究标准 / 临床指南”投影，不并入论文工作簿。公开目录每次读取当前最高版本，并要求该版本 `bibliographic/display` 的最新决定为未过期 `approve/public`；AI 检索还须该版本 `bibliographic/ai_retrieval` 的最新决定同时有效，以及当前具名 Agent 授权。撤回、过期、新版本或权限失效即不再交付；没有持久化的真实审核决定时公开目录和 AI 检索均保持空态。公开字段仅为已核对的题名、类型、编号、原始疾病、来源名称和原始来源 URL；无 URL 不生成虚假原文链接。原始文件名、SHA、审核依据和审核人只留在管理员入口，不在公开投影。

本轮投影进一步钉死**首批导入的 v1 与五个原文件 SHA**。现有标题、疾病等字段存于文档主表，尚无新文件版本的受控字段快照；因此即使未来对 v2 作了审核决定，V0.2 仍必须拒绝展示/检索，直到版本化元数据提取与校对规格获批并实施。这个限制比仅凭“新版本重新审核”更严格，避免新内容误用旧标题。

摘要和全文虽然在审核表内有独立用途决定，但目前没有对应的受控文本版本与字段级内容映射，因此 V0.2 **不展示、不供模型读取，也不称为已检索全文**。后续应先做原文提取、字段与页码/段落定位、校对及权利确认，再按相同版本和用途门禁接线。测试中的模拟批准必须事务回滚；不得以用户本轮“批准继续实施”替代管理员逐项权利审核。

## API 与 UI/UE

- `GET /api/hub-sources/external-review-items`：只返回五份当前元数据、版本指纹和六个字段/用途组合的最新决定；不返回原文字节、联系人或私有凭证。
- `POST /api/hub-sources/external-reviews`：提交单份单字段单用途 `approve`/`revoke`；固定公开用途受众、具名合成管理员与当前版本；必填权利依据和人工确认。返回追加事件版本。匿名、普通科研人员、旧会话、跨租户、非五份来源、旧文件版本、重复/冲突及缺依据均拒绝。
- G02 只在现有五份目录卡加入审核表单和逐组合状态，不动公共 Shell、工作簿审核或其他页。可读说明/错误/输入为工作区 14/22，元数据 12/18，长标题可换行；加载、失败、受限、保存中、成功、版本冲突均显式反馈。危险的批准与撤回需复核目标、字段、用途及影响；无自动批量放行。

## 验收边界

纯契约、真实合成 PG 事务回滚、HTTP 权限/输入、G02 真实浏览器与构建均留痕。浏览器可验证管理员选择和失败保护；若没有真实权利依据，不在持久库制造批准，也不宣称公开页面或 AI 已检索五份资料。生产迁移、真实发布、付费模型调用与专业内容验收均不在本切片。
