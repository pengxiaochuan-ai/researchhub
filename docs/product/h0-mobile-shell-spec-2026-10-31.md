# H0 真实领域页移动端公共 Shell 修补规格

日期：2026-10-31。范围仅 H05 领域目录与 H01 领域总览的真实模式；显式演示、其他业务页、桌面 Shell、权限和数据接口不变。两页沿用 G02/E01/E02 已存在的移动端公共 Shell 规则，不调整 Frozen Token、桌面 64px 顶栏/220px 侧栏或五个一级导航，因此不新增全局 Shell 尺寸决策。

## 问题与验收

- 修补前真实 H01 在 390px CSS 视口的正文宽度约 154px：固定 220px 侧栏仍占空间，导致题名与来源卡纵向碎裂。H05 同属真实领域入口，纳入同一回归范围。
- CSS 视口不大于 900px 时，两页收起固定侧栏、正文占满可用宽度；提供可见的「平台导航」按钮打开原五个一级导航。抽屉打开时遮罩后的页头与正文不可聚焦，Tab/Shift+Tab 焦点留在抽屉及关闭按钮内；关闭后侧栏不可聚焦，点击遮罩、Esc 或再次按按钮可关闭并归还焦点，切回宽屏也须恢复页头与正文交互。顶部保留品牌和账号入口，页头、面包屑与导航不得遮挡主要内容。桌面仍维持原固定侧栏。
- H01 的题名、说明、来源状态与卡片文字保持原字号角色，优先折行与单栏，不用缩字、裁切或假数据解决布局。H05 目录卡和关注/进入入口同理。
- 在 390×844、320px、1440×900 与 Chrome 原生 200% 缩放下验证无根级横向溢出、可读宽度、关键入口可操作，含主导航键盘/点击/Esc/焦点回归。显式演示的既有未适配状态不由本次真实模式修补覆盖，但不得因新增选择器额外改变。保留真实接口响应、截图与录屏。390/320 的断言不能代替原生 200% 缩放。
- 仅本机专用合成环境。技术浏览器验证不等于专业用户体验签认，也不开放新权限、云资源或发布。

实施：给真实 H05/H01 加入现有 `data-hub-source-real` 响应式消费者清单；只为这两页补可达的折叠侧栏入口与 H01 页内导航滚动。先运行可复现失败断言，再做最小修补及回归。
