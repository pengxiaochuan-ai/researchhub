## 范围与复用

- 科研资产 A01 增加知识资料入口 K01；K01 使用现有 Shell，管理员在同页进入治理模式。不改 S10 产出职责或一级导航。
- 受控复制旧知识库组件及编辑器（保留源路径、SHA256、适配说明），不依赖仓库外文件；使用原 `/api/knowledge/*` API，不建平行知识表，不修改旧项目源码。
- 独立同源 iframe 承载旧组件能力，避免 Tailwind/编辑器 CSS 污染 ResearchHub。iframe 内映射现有品牌 tokens；不嵌入旧 Shell。
- 同源 HttpOnly 会话，以 `/api/auth/me` 返回的实际课题组及研究项目选择上下文；无成员授权显示邀请提示，不自动创建 Study/成员关系。客户端选择不是授权，后端原 guards 和当前授权检查仍负责裁决。
- 新建库、列表/树、详情、编辑/CAS、审核、原文件导入/任务状态、向量检索、版本和回收站复用旧链路。前端不扩大可见范围、可写范围或管理员角色。
- 本轮不接通计费 AI 问答；界面明确说明，不能把知识检索成功称为科研 AI 全链路交付。

## UI/UE 验收

- 操作正文/按钮/输入 14px/22px；长文阅读和编辑正文 16px/28px；元信息不低于 12px/18px。页面外壳、导航和身份区保持原样；功能区另标实际会话身份。
- iframe 隔离的能力区保留文档树与编辑/预览布局；窄屏用原标签切换，不缩字。保留未保存离开确认；409 不覆盖本地草稿，提示复制草稿并重新打开最新版本。
- 加载、空库、401、403、不可用、导入待处理/失败分别显示；不回退演示资料。上下文变更卸载整个能力区，迟到响应不能跨 Study 显示。重复提交需抑制。
- 不自动执行 AI/外部连接器；不上传真实材料。浏览器仅放行本轮本机新服务。
- 管理员也不绕过课题组 `knowledge.edit`；只读成员不出现可提交编辑。个人库所有者审核沿用后端既有能力，不新增审核角色。
- 新建/编辑等相同在途请求按实际研究上下文合并，不自动重试；任务进度仅在本标签页保存当前账号/课题组/项目/库的任务 ID 与上传文件名，不缓存正文、密码或 JWT。刷新后主动“恢复本页导入进度”，只查询已提交任务，不重新上传；涉及身份标识仍须显式决定保存/不保存。
- iframe 中的模态按宿主页当前可见区域定位并可滚动，保持焦点圈定、Esc 和返回焦点。真实 200% 缩放下完成输入/创建/保存；不把窗口尺寸模拟当浏览器缩放，不外推为整个 Frozen Shell 的窄屏验收。
