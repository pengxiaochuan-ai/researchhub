## 2. 专业材料与产品含义

### 学术共同体已有基础

`灵枢心域政绩观党课.pptx`实际包含2页，第1页为线上讲座，第2页为线下活动。材料说明中医与心理学、哲学、人类学等多学科交流和中医心理学/社会心理服务；属于共同体发展背景。

产品处理：P007不只介绍发起者，还展示经过确认的既有系列讲座、线下活动和共建内容；增加活动目录/详情、回放/资料、投稿/贡献意向。共同体主题可比首期临床Hub范围宽，不能把每一讲座主题都纳入针灸临床研究数据集。材料中的期数、参与/阅读/浏览数字是该材料时间点记录，不作为2026-10-14实时统计；“本周日”的旧会议信息不作为现在报名入口。

合并表字段包括来源库、题名、作者、单位、文献来源、关键词、摘要、发表时间、第一责任人、基金、年、卷期页、分类号、ISSN、URL和DOI。适合首批文献元数据/知识库，不能直接充当结构化临床研究、注册、方案、访视或CRF数据。

抽查与关键词筛查可见临床、综述、机制/动物研究和方案文章等混合内容；题名/摘要命中只是候选标签，不作为人工确认的研究类型或疗效证据。导入流程需要“文件批次→原始行→规范文献→去重复核→领域分类→人工纳入→检索”，完整保留file/sheet/row/hash及来源关系。

### 专业方向与检索式

优先方向已由王教授说明为抑郁、失眠、认知障碍。宽检索式含中医病名、现代诊断名、症状词和针灸干预词；这些类别不能简单当成互为同义词。疾病、症状、中医病名、干预分别建术语与映射，保存原文、来源与专家确认状态。

认知障碍/轻度认知障碍/MCI等在所给中文检索式中未显式列出，与重点方向及代表性研究不完全一致。建议补充候选词并由教授确认，不擅自把“痴呆”“阿尔茨海默病”等全部作为同义词。现有术语覆盖也不能保证召回所有认知研究。

`SU`保留为教授提供的原始检索语法；CNKI、万方、维普、PubMed、WOS、Cochrane分别保存适用字段、检索语句、日期、版本和结果数。英文范围待教授后续资料，不以机器翻译自动定稿。taVNS等经皮耳穴电刺激与传统耳针分开记录，是否纳入统一针灸干预范围需确认。

## 4. “科学问题、研究方向、申报内容”怎样提供

不必让教授重新写一份平台PRD。建议接受已有申报书/方案中相关段落，团队帮助提取后给教授确认。

| 信息 | 教授可以提供什么 | 平台整理为什么 |
| --- | --- | --- |
| 领域研究方向 | 疾病/人群、干预、机制/疗效/预防等主题，以及优先顺序 | Hub方向及证据分类，不是一个具体Study |
| 科学问题 | 想回答的临床或机制问题、已有认识、尚缺什么证据 | Project内问题；临床问题可整理PICO，机制问题保留适用问题结构，不强制所有问题PICO化 |
| 申报研究内容 | 申报书“研究目标、内容、关键科学问题、技术路线、任务分工”等已有段落 | 项目目标→子课题/任务→Study/实验工作包→方案与产出 |
| 代表方案 | 完整方案及版本、访视表、CRF、分析计划、伦理/注册信息 | Study配置、采集字段、检查规则、分析与治理 |
| 实际团队流程 | 谁在何时设计/登记/采集/核查/签署/分析/投稿，使用什么表或系统 | 任务与责任矩阵、权限Scope、流程状态 |

例句仅用于采集需求：“希望研究某针灸干预对某类失眠患者的睡眠及相关情绪结局是否有帮助。”研究对象、干预、对照、指标和时间均由教授/团队方案提供，不据例句建立试验。
