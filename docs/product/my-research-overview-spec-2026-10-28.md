## 目标与边界

P01 只展示当前登录账号在当前租户内、当前有效研究组和项目成员关系所允许的数据库记录。新注册账号即使属于灵枢心域租户，也不因注册而获得私有 Study 数据。页面不再使用王教授、固定项目、入组趋势、AI 判断、简报或本地浏览器草稿作为业务数据。仅在本机专用合成环境验证，不改旧系统服务、角色、Schema、临床库、云或发布配置；不发起模型调用。

## 只读接口

`GET /api/my-research/overview`：要求有效服务端会话，不接受客户端 tenant/account/project ID。后端在同一授权事务中重新读取有效账号、租户、研究组成员、项目成员和角色；只返回各关联对象 tenantId 与当前租户一致、两层成员均有效、项目/研究组均 active 的条目。租户管理员身份不自动扩大私有 Study 可见范围。响应：

```json
{
  "profile": { "displayName": "...", "tenantName": "..." },
  "studyGroups": [{ "id": "...", "name": "...", "projects": [{ "id": "...", "name": "...", "description": null, "status": "active", "canReadDrafts": true, "canReadTasks": true, "canOpenDesignWorkspace": false }] }],
  "summary": { "projectCount": 0, "ownDraftCount": 0, "myOpenTaskCount": 0 },
  "drafts": [{ "id": "...", "studyGroupId": "...", "researchProjectId": "...", "title": "...", "updatedAt": "ISO", "version": 1, "canOpenPlanFlow": false }],
  "tasks": [{ "id": "...", "studyGroupId": "...", "researchProjectId": "...", "title": "...", "status": "open", "dueAt": null }],
  "activity": [{ "id": "...", "title": "...", "updatedAt": "ISO", "researchProjectId": "..." }]
}
```

草稿仅本人拥有的未删除 ResearchArtifact，且具备原 `artifacts` 菜单和 `artifact.read` 权限；任务仅本人被分配的未关闭 StudyTask，且具备原 `workbench` 菜单。摘要总数来自数据库 count、列表最多 5 项，活动仅来自本人草稿最近变更；不推断入组率、证据相关度或 AI 结论。缺少持久化个人 Brief/Hub/预测结果时页面显示“不展示，尚无可核实的服务端结果”，不伪造 0 或固定内容。接口 401/503 与空数据分别处理，不回退演示。

本机运行时实现复用旧 Auth Guard、成员/项目/产物/任务表，接口本身只读；旧应用源码、Schema 和角色不改。`canReadDrafts`/`canReadTasks` 仅控制服务端查询；`canOpenDesignWorkspace` 和 `canOpenPlanFlow` 还须与本机已接通的 Q02/Q01 接口作用域完全一致，不能把一般旧产物或其他项目导向必然 403/404 的入口。当前 P01 不展示旧固定 Hub、简报、入组图、AI 分析和演示通知/搜索；这不代表这些能力已实现。正式部署还需把本机聚合适配纳入 ResearchHub 独立服务发布流程并做目标环境四层验收。
