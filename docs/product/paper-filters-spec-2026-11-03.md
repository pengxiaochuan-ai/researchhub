# E01研究论文分类与筛选

状态：本机技术交接，专业验收待用户；[实测与明确限制](../testing/publication-filters-2026-11-03.md)。

## 用户路径和不变边界

在原左栏输入关键词/选择条件→原“应用筛选”→中栏获准匹配结果及计数→选择文章→右栏核对分类依据/摘要→E02原详情→返回；移除已应用标签或“清空全部”回到对应条件第一页。未应用修改不改变结果；请求失败保留输入，显示错误并可重试，身份改变清空私有结果/计数。

原三栏、分组顺序、原操作位置、字号和滚动保持；分类信息使用既有论文标签槽位/右栏“研究设计”，不新增管理步骤或更改审核。G02对内容的一次范围决定继续适用，分类不自动放行任何来源。

## 数据契约

现有两张来源规范/版本表增加可空classification JSONB，包含schemaVersion、extractorVersion、sourceHash、字段输入摘要及有依据的claims。每条claim记录facet/value/field/quote/rule；类型、研究设计、人群、干预、疾病、语言只基于原题名/摘要或JATS本篇front元数据；不扫描参考文献推断。无法识别不写肯定标签；原元数据缺失不补造。审阅者可在原预览研究设计Tab核对依据；不把自动提取称人工核实或证据评级。

日期保留来源精度year/month/day，近N年按当前UTC年及之前N-1个发表年份；自定义范围按已知日期区间完整包含，单年信息不伪造月日。语言仅认源XML声明；无声明不按英文字母猜。全文筛选含义是“当前获准正文可读”，不等于原文全部组件齐备。期刊分区无权威年份来源，显示未接通，不伪造评级；不扩展采集任务。

## 筛选/统计接口

扩展原publications/member/publications GET，可选filters为有界JSON字符串，包含year(any/1/3/5/custom)、from/to(ISO日期)、types/designs/people/methods/diseases/languages多选值及fulltext(any/readable/unavailable)。同组OR、跨组AND，枚举白名单和日期校验，未知参数拒绝400。年份以外每组允许unknown；识别为其他与未识别不同。

items增加classification（当前允许字段支持的claims/values）、日期精度，counts.matchedRecords为当前完整组合总量；facets返回排除本组条件、保留关键词和其他组后的各选项数量及未识别数量。统计绝不基于当前页，且只限当前账号可见和获准字段。page limit真实生效，游标包含完整filters指纹，跨条件/账号/授权版本拒绝复用。

## 验收标准

1. 原文元数据/清晰原题名与摘要提取可追溯；综述/Protocol/动物研究不误标已完成的人体RCT，否定/背景提及不充作确定设计。
2. 所有存量来源有提取结果或明确空/错误状态；重复回填无新增版本、原始文本/哈希/审核不改。
3. 单条件、同组OR、跨组AND、关键词组合、未知标签、空态、年份/日期边界、非法参数与注入均有自动测试。
4. 真实PG中分页前筛选/全量分面计数，连续翻页不重不漏，跨条件游标拒绝；未审/撤审/租户及摘要撤回不泄漏标签和数量。
5. 原两账号及匿名Chrome真实勾选但未应用→应用→预览→详情→返回→加载更多→移除/清空；503/迟到请求不串结果，截图/录屏、四宽度和真实200%留证。
6. 单元/集成/构建、独立总评审及产品文档同步；专业分类准确性仍由用户最终评审，不用测试数量代签。
