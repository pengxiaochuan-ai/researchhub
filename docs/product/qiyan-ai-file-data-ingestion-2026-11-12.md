- 研究数据：上传→只读识别/预检→一次汇总确认课题及映射→正式导入→被试/访视、任务、质控与结果可回看。
- 原数据Agent所有仍有效能力列入复用清单逐项验证，分步不是删减目标；检测退役能力、任意新算法与原本不存在的通用分析不计入“全部”。

选择理由：用户已同意“统一入口＋自动分流＋数据入库一次确认”。备选“先离开对话去知识库/数据页上传再回填”增加操作；“模型识别后直接落被试库”可能写错课题/被试且无明确确认，均不采用。两套Agent界面也不作为默认。

本机仍仅专用合成环境。此文不授权建表/数据库GRANT、增加角色或额度、调用新收费服务、访问远端配置、云资源或发布。实现层发现这些依赖时按具体最小差异停线确认。

## 3. 用户路径与操作负担（实施验收契约）

### 3.1 统一上传

沿AI01原“上传文件”选择器选一份或多份；不先问“知识/数据/算子/知识库ID”。系统按内容签名、容器、表头与现有检测器分流，扩展名只是候选。明确文件直接走对应路径；真正歧义时只问有歧义的文件用途，可批量选择。混合批次分开显示，不要求整批强制选一种。

附件清单在输入区附近紧凑显示，包含名称、安全显示类型及真实阶段；多份可折叠。消息区保留给分析，不增加常驻教学卡、独立管理大面板或右栏。原历史分组/一行标题、两行自适应输入、Enter发送/Shift+Enter换行、排队编辑删除和智能搜索OFF默认保留。联网只由用户显式开启；上传本身不触发联网。

### 3.2 文献路径

选择文件后自动私有保存/解析，不让用户再选库、手写题名、配置分块/向量/版本或逐篇审核。已存在适用本人私有库则复用；需要创建时服务端按当前真实授权工作区幂等建立默认个人库，无假成员或虚构Study。库名不是归属依据。

旧private库仍有group/project边界。会话有效范围已确定时库跟随该范围，不选“列表第一课题”作为新业务决定；无可信工作区时只能本人隔离暂存，明确尚未完成知识入库，不偷偷把资料放到共享库/旧Study。如何建立合法工作区属于部署/账号准入，不绕过权限；未具备时在本片准入明确阻断而非声称通用注册账号已可用。

解析完成可直接用原发送动作基于已附材料提问；不要求先到K01发布。文件选择只触发解析/索引，不悄悄调用付费LLM；用户发送的那条问题可等待所选资料就绪后按队列执行。没有提问时不自动生成长总结或新增模型任务。现有文档可在会话中自动使用关联集合，不重复上传/逐问选择；新问题可调整附件范围。

### 3.3 研究数据路径

上传只进入本人暂存，识别、预检阶段**不创建/更新Subject、Enrollment、Visit、Feature或正式ProcessingTask，不触发确定性处理与模型分析**。可保存隔离上传/预检记录；不得拿旧`ingestRaw`先写入再事后问用户。

同一个内联确认区集中显示：

1. **目标课题与研究Study**：只列本人当前有导入权的真实对象；课题可能有多个Study，不把课题意图ID当执行项目ID。
2. 被试编号/已有匹配或新建数量、需要的访视、字段/单位映射摘要。
3. 文件/行数、将新建/追加/拒绝的内容、必须处理的异常。

主动作只有“确认导入”；确认区本身就是明确决定，不再弹同内容二次确认。详情按需展开，不把全部映射、hash、任务版本堆在首屏。一个批次一个目标Study；跨Study材料必须拆成独立计划，不做隐藏的多课题写入。

从可信Study入口进入可预填课题/Study；只有一个有权目标时也可预填，但目标名称始终在确认处可见；多个Study且缺上下文只选择一次。课题/Study变更后重新预检绑定和映射，不沿用旧被试/访视，不自动提交。**目前AI01读首个项目的技术scope不能成为确认目的地的依据。**

已可靠匹配的被试、唯一适用访视及字段由系统预填；只突出缺失/冲突/有多个候选项。能按已有规则批量解决的逐列/规则确认，不逐行弹窗；新被试编号必须合法假名化，不能由模型猜身份。无需访视的档案字段不强迫补访视；确需访视但无法唯一确定时才请求选择。

常规同构批次完成上传后，仅一次“确认导入”，无二次同义确认；歧义/身份风险/冲突是真正例外并单列，不为追求一次点击绕过。错误定位至文件/工作表/行/列，保留安全输入，仅更正出错项，不要求全部重填。

### 3.4 反馈与恢复

原位呈现已上传、解析中、待补信息、待确认、导入中、已导入/部分拒绝、失败；这些是投影语义，后端须映射真实记录，不先造一套万能枚举。只给实际进度，不虚构百分比。

成功给出导入摘要与真实被试/访视/处理结果回链，不要求复制ID去检索。导入完成不等于质控合格、访视完成、正式入组、审批或锁库。

断网/超时结果未知时只查原请求回执，不重新上传/导入/调用模型。普通503保留安全草稿；切账号、失权或目标撤回清受限正文和待发对象。新会话不沿用旧未发送附件；切回原会话从服务端恢复。关闭确认区不宣称取消后台已提交任务。未提交选择移除与已入库文档删除区分，后者沿原回收/保留规则。

## 4. 数据关系与写入边界

Hub课题意图→产品Study→统一解析出的旧ResearchProject执行容器；Subject同时绑定tenant/group/researchProject，假名编号在此范围唯一。Enrollment、SubjectVisit继续关联Subject及Protocol版本；不得用课题组替代课题或只挂账号/session。

跨课题同编号不自动合并；建档和导入不自动入组。目标Study、当前权限、文件hash、已确认映射及当前数据版本组成不可变导入计划。确认后若任一关键条件改变，原计划不能提交，必须返回差异并重新确认；不静默改写确认对象。

可新建假名被试或追加本人有权的已有被试。Study可读不等于可导入：目的地选项和提交须核对当前真实导入授权、执行政策与已启用的能力；未开放采集/需额外同意的研究不能仅凭data.upload或管理员标签放行，不在本片顺带启用整个正式采集体系。现有值冲突默认不覆盖，预检给明确差异；更正走既有理由/版本/审计流程，不能用上传旁路绕已提交/锁定数据。未知单位保持未知，0/false/空白有区别，不自动换算、补值或推断随机分组。

批量语义：预检先按规则排除确定错误，确认页列明实际范围；本首批同构导入计划的业务数据库写入要求全成功或回滚，旧服务若仅有自建事务须先抽取/适配最小事务核心，不在循环调用后声称整批原子。对象存储不是PG同事务：保留随机暂存对象及状态，失败不删除提交结果未知的文件；后续保留/清理沿旧策略，不自行清历史。

## 5. 私有知识、AI与资料范围

入个人库的文献保留draft/reviewed=false。本人材料分析只接受当前上传/会话显式关联的doc/source file版本，要求库private且owner=当前账号、tenant/group/project匹配、安全检查允许、文件hash/解析版本/内容当前、未删除。普通管理角色不因此得到其他人的私有聊天或知识全文；Study业务管理员权限按ADR-0006单独执行。

该读取是“本人上传材料”，不是`knowledge.search`或“已审核Hub证据”。工具输出、历史和答案注明来源类型及实际读到的范围。无权、blocked、身份风险尚待处理、解析未就绪、无法验证版本均不进模型。安全warning复用原决策，不以用户希望简便为由标为allow。

本人私有内容不得进入他人的检索、公共向量召回、公共Hub或共享资产。共享/发布/审核仍走原明确操作，不因本功能增加自动审批。不要通过把reviewed=true/published当作“本人可分析”的实现捷径。

使用旧OpenCode＋DeepSeek BYOK与当前Skill版本/装备/调用授权，服务端给受控工具上下文，不把原始研究数据、任意storage key或SQL交给模型。文献可发送经授权的最小必要解析片段；研究数据只发送确定性处理摘要及必要假名字段，原始媒体/可识别文件不进入LLM。科研数值由解析/算子提供，AI只编排与解释。

每条引用固定file/doc版本、hash、页/章/段/表格单元位置（真实存在才显示），包含读取/截断/失败范围；扫描/OCR低置信明确标注，不宣称所有表格/图片无损恢复。长文开头/中段/尾部均测，索引最多200块等旧限制不得静默截断后声称全文分析。缺失位置不伪造页码。

新附件进入会话不反向改变历史答案证据。命令入队时固定自己的附件集合；后加文件不加入已排队问题，编辑待执行问题时可显式更新附件并增版本。准备、实际工具/Provider前、提交、历史读取和来源下载均重验当前授权/版本；未知用量沿原预留/对账，不零用量释放或自动重试。

## 7. 全部旧能力承接与分期

先交付“资料上传→私有库→带引用分析”完整切片，再交付“数据识别→确认课题→档案/表格入库→结果解释”，随后逐项补齐旧数据Agent有效路径。总目标不缩为CSV单模板；每种模态/Skill独立证明目标环境配置、真实调用及结果。

格式和容量复用旧有效契约，但实际入口取各阶段最严格限制，不把上传上限当处理能力：文献100MiB/批20份；聊天全量结构检查部分格式25MiB，其他500MiB；原始视频500MiB、音频100MiB、表格500MiB只是各自入口规则。连接同一入口前逐格式明确生效上限、分块/完整检查与内存代价，不把结构化格式都宣称500MiB。

PDF/DOCX/TXT/MD先验证；DOC/PPTX/HTML/EPUB/MSG/IPYNB依赖实际parser启用，扫描PDF/OCR和表格位置单列。数据CSV/TSV/XLS/XLSX/JSON逐项覆盖；眼动/档案、原始/标准/预处理及其他旧分类有独立正反例。fNIRS/媒体/压缩包只按旧实际确定性能力承接，解析/算子不可用明确阻断，不以“上传成功”顶替处理完成。VA/星辰检测等退役模块绝不恢复。

旧research/data工具类型互斥：推荐Hub统一入口后受控调用数据专用执行服务和既有事务核心，而不是修改旧TOOL_CATALOG全局开放。若需额外工具授权、Skill发布、后台扫描或旧源码修改，列具体最小差异待确认，不借“全部能力”扩成全底座重构。

| D04 | 所选批次与课题/Study、执行项目、被试/访视真实父链可从S03/S04/S09回看；导入不自动入组、完访、质控放行或锁库 |
| D05 | 旧全部有效路径逐项通过复用清单，媒体/fNIRS与未启用算子不能以triage成功销项；旧服务和历史任务不变 |
| R01 | 本人历史/刷新/队列编辑、同键冲突、断网/503/提交未知、切课题/身份及迟到、原件读取关闭均有真实HTTP/PG与Chrome证据 |
| R02 | 多账号不同材料同时执行、同session有序、材料集合冻结、账本与任务一一对应；Token预留不是容量压测结论 |
| R03 | 对每条常规路径记录选择/补填/确认次数、完成下一步是否清晰，用户实际验收；真实桌面/窄屏/200%截图WebM，非Mock冒充 |

四层永久分开：代码契约→本机目标配置→全新合成材料真实工具/模型/写库→用户可用/专业一致。单元/集成/构建不可替代末两层。本轮为规格，只读核查，没有新增测试运行、上传、建表、权限/配置变更或模型费用。
