# 岐研AI · 转写、画面摘要与时间来源契约

日期：2026-11-16。状态：**本轮形成的建议契约，待评审，尚未实施内容理解**。用户要求语音转写和画面理解均支持，先旧数据流程、再内容理解；本机旧登记首片已完成技术交接。本契约不修改已确认页面布局、旧输入边界、权限、媒体原件或现有计费规则。执行器现状见[免费核查](../technical/ai-media-executor-audit-2026-11-16.md)。

## 1. 用户最终得到什么

2026-11-17已按用户要求完成[首切片最小规格](qiyan-ai-media-first-slice-2026-11-17.md)及[独立合成探针](../testing/ai-media-content-probe-2026-11-17.md)：基础真实ASR/画面/点击播放有证，静音补造经VAD前检方案处理，非零PTS归零失败不列支持。下面仍是完整目标契约；首片只交付转写、抽样画面和后台实际范围说明，AI综合推论/私有知识索引等分步实施，不由探针自动批准新表/权限/UI。

同一视频产生三类可核对结果：**自动转写、抽样画面描述、基于已处理证据的AI摘要**。每条能回到本次固定原视频的具体位置；能明确看出哪些时段/画面未处理、哪些内容是推论。自动转写和AI描述均为待核对结果，不把它们直接标成“原文事实”或人工复核结论。

普通讲座/科研说明视频不强制登记为被试资料；确实写入被试库时仍一次确认具体Study/本人被试/必要访视。先沿现有权限读取媒体，内容分析的许可独立核定；现有登记许可不是新增模型/转写用途授权。私有内容不会自动变为Hub公开资料或跨租户知识。

建议沿原视频区域展示处理状态及结果，默认操作由系统编排，不增加文件类型、模型、Skill、时间轴算法等选择。新增结果区/回放交互是未来待确认的局部UI差异，本轮不改页面；管理员也不另造总览模块，只在已有本租户有权对象上核对状态/失败原因与审计。

## 2. 来源身份：先固定哪一份视频

每次执行固定`tenantId/accountId/sessionId/mediaId`、原件SHA256/字节数、准备时媒体版本、明确流索引及`timelineManifestHash`；生成独立`runId/attempt/version`。被试入口还保存真实Study/Subject/可选Visit链，不依客户端文件名或storageKey猜父对象。

同SHA不代表自动跨账号/Study共享结果。执行前、分段认领、发布及每次读取都核对当前授权/来源状态；已准备快照发生未核准的版本变化时不得静默发布旧结果。来源撤回、越权、原件/版本不匹配或伪造引用属于必须停止的情况，不能只加AI免责声明后继续交付。

模型只能选择本次证据ID，不能创造URL、媒体ID、时间或跨文章来源；后台校验归属并渲染同源回链。日志不保存原文件名、逐字内容或本机路径；内容在受控私有派生区保存，不能送给Codex/Anthropic。

## 3. 一套原视频播放时间轴

对用户统一显示`时:分:秒`，内部用整数微秒（序列化为十进制字符串）＋原始PTS/有理数时间基。界面毫秒由后台按固定规则换算；不以显示精度承诺识别精度。

1. **原始PTS**：通过FFmpeg/ffprobe读取实际解码帧/采样的presentation timestamp、time_base、流起点、容器起点及edit-list语义，保存原值和工具版本。
2. **播放坐标**：建立版本化`timelineManifest`，将上述时间映射到原浏览器播放器的`currentTime`。不能一律减音轨首帧或仅用format.start_time；音轨可能晚开始，画面有VFR/B帧或非零起点。
3. **首次支持范围**：优先连续时间轴、无复杂编辑映射的现有MP4/MOV/WebM。必须用合成非零起点/晚音轨/VFR及真实浏览器核对回放；无法确定映射的容器标`timeline_unavailable`，保留原件播放，不提供伪精确回链。复杂edit-list、时钟跳变或重封装映射另列待支持，不能悄悄归零。
4. **抽帧证据**：每帧保存真实`pts/time_base/presentationUs`、streamIndex、帧ID、图像SHA、工具/变换版本。旋转、缩放/裁剪也记变换；不以帧序号÷平均fps计算位置，不用计划抽帧时刻覆盖实际解码时刻。
5. **精度分开**：帧PTS与采样映射来自工具；语音起止来自ASR的对齐估计。即使保存六位小数，也不能称精确到微秒或作为临床测量。

## 4. 转写如何回到原视频

默认保留原语种，翻译作为另一个派生版本，不把译文当逐字原话。首片不自动识别真实人名/身份，不把说话人序号当被试身份，也不声称已实现说话人分离。

音频解码为连续PCM时记录每段实际采样率/样本数和首样本对应的原视频位置。连续无丢采样的窗口内：

`原视频位置 = 该段首样本在原视频上的位置 + ASR在该段PCM上的相对位置`

这一步换算由确定性程序完成；ASR相对位置仍标`estimated`。例如程序核算：首样本对应原视频61.2秒，ASR区间2.35–4.10秒，回链区间为63.550–65.300秒。这个例子仅说明坐标换算，不是实际患者数据或准确率承诺。

| 情况 | 规则 |
| --- | --- |
| 切片后音频从0开始 | 保存真实原视频偏移后相加，不把切片0当原视频0 |
| 音轨比画面晚开始 | 保留实际偏移/空白，不将声音人为提前对齐画面 |
| 重采样、解码器padding/delay | 保存输入/输出采样映射及实际首样本，不能只记录目标采样率 |
| VAD/静音 | 首片建议保持原时间轴，只跳过无语音窗口；若执行器内部移除静音并已还原时间，明确时间域，不再还原第二次 |
| 拼接去静音音频 | 必须有分段映射；一句跨多个原始片段时保存多个sourceSpans。不能将跨停顿的句子伪装为连续原文，也不能仅加统一offset |
| 重叠窗口 | 以固定源窗口/样本边界和词级对齐去重；无法可靠拆分的重复句保留疑义，不让LLM改写成唯一原话 |
| 无音轨/无可识别语音 | 分别标no_audio/no_speech，不生成空想字幕；仍可独立做有权画面处理 |
| 听不清、专有名词或低置信片段 | 保留原识别及uncertain标记、可回听范围；不按医学常识补词。置信分数仅为该执行器输出，不跨模型冒充统一概率 |

人工修订另记版本、责任人与修改依据；不覆盖自动识别原始结果，不让修改文字悄悄改变原时间来源。需要更精确的逐词定位时另接强制对齐并单独验收，不用ASR输出直接宣称精确标注。

## 5. 画面摘要如何回到原视频

首片采用**真实时间戳抽样帧＋局部多帧描述**，不把文本模型当能直接读取视频。帧的选择由后台固定版本策略负责，保存实际选帧清单；策略间隔、场景变化和上限属于运行配置，不是用户多一步选择。

- 模型输入是本次获准帧及只读frameId；输出定性描述、明确选择的frameIds及不确定性，不输出自行推算的时间、动作次数/速度或医学量表数值。
- 后台将frameIds映射到真实PTS。单帧描述对应一个时点；多个抽样帧支持的范围只称“抽样画面描述”。不能把首尾两帧之间的全过程当已观察，也不能凭一张画面推断持续动作、情绪病因或治疗效果。
- 总结引用多个证据时保留各自时间范围，不合并成一个看似连续的“大跨度原文”。跨帧时序判断需要真实有序多帧证据，明确抽样范围和限制。
- 可读屏幕/字幕中的数字属于图像识别文字候选，保留帧出处及未核对状态；不直接写入量表、CRF或科学特征。计算、持续时间、频率和正式数值仍由确定性算子生成。
- 画面通道失败不得由字幕/音轨冒充视觉成功。无声视频可以独立完成抽样描述；全黑/模糊/遮挡等只说明实际可见范围，不编造未见信息。

## 6. 摘要、知识检索与引用

后台生成证据包，包含本次实际完成的转写片段、帧及已授权派生内容。研究Agent只接触任务所需的最小证据，不获得原件任意路径/URL或跨账号材料。需要把原始转写片段交给模型时，先明确新的Hub媒体用途和脱敏契约；旧普通对话的原始材料禁止规则不全局放宽。

答案分为：自动转写摘录、AI画面描述、AI综合推论；解释中的引用回到对应片段/帧。综合推论说明依赖哪些证据，不伪装为原话。用户问题超出处理范围时明确缺少什么，可继续交付已有有效部分；关键结论没有所选证据支撑时不交付该结论。

派生文字未来可作为本人/当前Study私有知识来源，但不自动发布为公共Hub内容，也不将被试视频与公共文献共用审核状态。正式入私有知识索引的范围、撤销传播与删除/留存规则在实施规格中单列，不将现有普通资料许可自动套给转写。

## 8. 状态、并发与恢复

音频/画面两通道独立状态：pending/running/complete/not_applicable/failed；总结果complete/partial/failed由真实通道和覆盖派生。单通道成功不能掩盖另一通道失败。请求未知沿原requestKey/已持久任务核对，不自动另建收费请求；离页后服务器任务是否继续，必须在真正接通后据实际Worker行为说明。

提交前重验当前源权限、真实父链、源/结果版本、任务状态/租约与证据归属；失效停止发布。可只重试失败片段/通道，保留已成功结果及原尝试/费用；不重放旧原件登记。并发/CPU/内存/模型加载队列在媒体执行层有界控制，不持PG锁等待推理，不影响旧系统Worker。

## 9. 验收落点

1. **合成内容真执行**：至少中文已知文本语音＋可见画面、无音轨、无可识别语音、损坏/不可用、长时分段；真实ASR/视觉请求及模型/配置版本留痕，不能只Mock。
2. **时间映射**：非零起点、晚音轨、VFR/B帧、切片、跨静音/VAD、边界词/重叠；确定性检查映射不串源，真实播放器点击定位并核对。ASR语义边界容差与文字准确率在合成金标准阶段测量后设门槛，不提前宣称精度。
3. **来源一致**：模型虚构frameId/时间/引用、源版本变化、撤权/切账号、迟到响应、丢提交响应均不串读/重复；未读画面不称已看完整视频。
4. **用户操作**：原视频区域直接看结果并点时间回放，既有被试登记保持一次确认；不增加模型/算法/内部版本选择。任何局部布局差异先给具体方案确认。
5. **四层分列**：代码存在→目标配置/模型就绪→真实工具执行→研究者可用；缺一项不称视频理解完成。本轮只完成核查和契约。
