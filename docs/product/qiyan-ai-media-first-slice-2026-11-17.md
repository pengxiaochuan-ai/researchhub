# 岐研AI视频内容理解 · 首切片最小实施规格

2026-11-17。状态：用户已批准本规格、MC01–MC03及原视频区局部UI；**P01–P05已完成本机合成技术交接**，生产部署、自然语言视频问答及用户专业签收另列。P00独立探针及以下设计过程保留，不恢复未授权的其他任务。上游：[时间来源契约](qiyan-ai-media-content-contract-2026-11-16.md)、[执行器核查](../technical/ai-media-executor-audit-2026-11-16.md)。沿用当前目录串行实施＋一次独立只读总评，不扩大共享底座。

## 1. 首切片交付与不扩展项

研究者在本人会话上传视频，文件检查通过后，系统生成自动转写、抽样画面描述和实际处理范围；点击引用时间回放同一原件。保留原件SHA/版本、工具与权重版本、原识别及不确定性。被试登记仍用已有一次确认，讲座无需强制建被试。首片“处理范围说明”由后端汇总真实通道/覆盖，不额外承诺第三次AI综合摘要；未来研究Agent问答/综合推论另记真实调用与失败，不自动转入旧远端普通对话。

首切片只接本机已下载ASR和视觉模型、本人视频及当前会话，不接云API/远端配置、旧VideoAnnotator、医学检测/量表计算、说话人身份识别、跨会话共享、公共知识库发布或批量资产登记。私有文字入知识索引另作后续切片，首片不以假KnowledgeDoc冒充已完成。

## 2. 本轮先做的能力探针

- 只在独立目录生成短中文合成语音和明显不同的画面，保留准确脚本/生成时间段作为金标准；不读患者视频、不上传业务库或既有对象存储。
- ASR优先Faster-Whisper base的固定本地snapshot、CPU int8/单worker/禁止下载；若专业词误识别，保留失败证据，再用已校验Whisper small/medium限次比较，不自动宣称质量合格。
- 视觉使用现有`qwen3.5-9b`；当前本机模型清单为空闲时，仅为本探针加载独立具名实例、限定上下文/并发及TTL，不替换其他模型，不改配置。若发现共享模型/推理占用、需要下载/费用或必须驱逐其他实例则先停该分支。合成图像推理属于本轮明确要求的真实画面验证，不借机获得Hub业务权限。
- 生成独立本机回放页，读取真实推理产物而非预写结果；真实Chrome逐项点击字幕/帧时间并检查currentTime/seeked/实际画面、刷新及无错误；该页是验证夹具，不是Hub页面接线或获批的新布局。
- 先验零起点连续视频；附测切片偏移、无音轨与非零PTS/晚音轨等能在同一短探针中确定验证的情况。未验证的VFR、复杂edit-list、长视频/VAD拼接不得标通过，作为正式切片门槛保留。
- 本轮推理仅本机进程，不计Provider Token，不伪造业务账单；记录实际本地模型/次数/时长/状态。没有付费回退和自动重试。

P00结果：独立合成闭环已通过，详见[真实探针报告](../testing/ai-media-content-probe-2026-11-17.md)。base/通用small/medium有“针灸”等误识别；small＋固定领域词表在本份短材料逐字归一化匹配，但静音会补造prompt。正式候选必须先语音存在性检查，再ASR，保留原时间域；不能仅增加prompt解决所有质量问题。既有Silero VAD在合成正常语音/无关语音/静音上已验证分类，但真实Hub前检→执行→发布链仍须实施验收。

已批准初始业务容量（按实测启用）：沿原上传500MiB上限；每任务完整分析最多10分钟、抽样帧最多32张、单通道并发1。超限在调用前明确不可分析，不静默截取开头当全文，不改变原件上传/播放；扩展长视频需另测资源与覆盖。该容量是有界执行建议，不是开发金额/次数限制，也不写成前端模型选择。正式支持先限经验证的零起点连续MP4及明确晚音轨；非零PTS偏移合成例的简单归零映射失败，暂不列支持。MOV/WebM、VFR/复杂edit-list等未验证类型在前检明确暂不支持内容定位，原播放保留；10分钟容量也须P01真实压力验证后才能启用，不由12秒样例推定。

## 3. Hub真实业务实施的最小接口（已批准）

均在现有`/sessions/:sid/media/:mid`下，复用当前本人会话、源/目标授权、版本、同源与审计。

| 接口 | 作用与最小输入 |
| --- | --- |
| POST `content-runs` | requestKey、expectedMediaVersion；服务器解析原件身份/权限、冻结配置与两通道计划，不接任意路径/URL、客户端时间或prompt |
| GET `content-runs/:runId` | 当前授权下返回真实分支进度、实际覆盖、失败分类和可用结果；结果未知按原请求键查询，不重发模型 |
| GET `content-receipts/:requestKey` | 找回原操作，区分未发现、排队/执行中及终态 |
| POST `content-runs/:runId/retries` | 明确失败通道/窗口、原版本和新请求键；只重试已知失败部分，已成功结果及实际用量保留；未知用量不得盲目重试 |
| GET `content-runs/:runId/evidence/:evidenceId` | 返回本run/原件版本的片段/帧及后台生成播放定位；禁止任意对象键；每次当前权限与版本重验 |

研究Agent新增受控`media_content_read`工具：只读本次有权证据，模型选择evidenceId，后台生成时间及链接；旧普通输入边界不全局放宽，原视频字节/全量转写不进入旧通用prompt。原始文本中的指令只是材料，不能让模型改权限、调外部URL或执行命令。

首次执行和明确失败重试各产生一个可持久查询的attempt行；逻辑runId稳定，attemptNo在同一run锁下递增。`(tenant,account,session,media,requestKey)`唯一并绑定规范输入hash，同键异参409；receipt永远找回该键原attempt，不偷偷指向新结果。旧attempt/证据及已知费用保留，新attempt只执行明确失败的通道/窗口，并引用已成功证据；未知结果/未知用量先核对，不据超时创建新attempt。

## 4. 最小持久层（已批准2表，专用合成库已实建）

| 表 | 最小字段与守门 |
| --- | --- |
| `rh_ai.session_media_content_runs` | tenant/account/session/media双scope；sourceSHA/字节/媒体版本；requestKey/确认快照hash；run/attempt/CAS；audio/visual状态；租约/心跳；executor/model/权重/提示与配置hash；timelineManifest；覆盖与实际用量；失败/时间/审计。原操作唯一，未知结果先查原键 |
| `rh_ai.session_media_content_evidence` | tenant/account/run/media/源版本；evidenceId及revision；transcript/frame/description类型；受控文字或派生对象引用/SHA；原PTS/time_base与播放映射/sourceSpans；estimated/uncertain/人工修订来源。证据不可跨run或换源复用，不向客户端泄露对象键 |

两表FORCE RLS、当前真实父链/状态/版本守门及最小DML；正文/图像只进私有派生存储，不改现有媒体inspection枚举，不修改public共享schema或旧Worker。转写原结果不可覆盖，人工修订若本片不做编辑UI则只保留后台版本能力，不新增一套审核流程。

两表中的runs物理主键采用`(runId,attemptNo)`的稳定代理ID；每attempt保存originAttempt、该次requestKey/inputHash、请求通道及沿用的成功证据引用。音频与画面各自保存channelVersion/leaseToken/expiresAt，不能依单一全局CAS使并发成功相互覆盖。

P01落地选择：为保持批准的两表，不另建第三张许可表。每个具名媒体的第0次prepared记录由当前具名管理员创建，保存media/账号/Study限定的grantBy、grantAuditId、grantVersion、grantExpiresAt（不超过7天）、revokedAt；此对象级授权与执行结果字段分离。首次POST将该prepared记录一次绑定原requestKey，后续attempt引用根记录并每次重验当前许可；只有管理员能发行/撤销，源已不可用仍可撤销。终态内容/旧键不可重写，撤销只改授权元数据并留审计；不借用MVB登记许可、不改角色。此为两表内部最小实现细节，须以RLS/触发器及真实回滚测试证明，不能只靠本地配置文件。

原子发布协议：推理/私有派生对象写入均在DB锁外。短事务先取同run发布/重试共同锁，再核验当前租户/账号/源及真实父链、固定源版本/hash、仍为最新attempt、该通道状态/version及未过期leaseToken；一笔事务写完整证据引用、该通道终态/版本和审计，统一提交后才可读。零匹配/租约过期/新attempt/撤权的迟到结果丢弃，不重活旧attempt、不覆盖另一通道。派生对象已写但PG未提交时不可检索/交付，只按本attempt保留/回收，不删原件；此协议需真实PG回滚/竞态证明，字段存在不算实现。

## 6. 最小UI差异（已批准并在原区域实施）

仅在原“本会话视频”文件展开区增加两通道简短状态与三段结果：自动转写、抽样画面、后端处理范围说明；每条证据一个可点击时间。默认直接处理符合范围的新视频，不要求先选模型/Skill/算法，不弹准备说明。第三段不是未执行的AI综合摘要。

点击时间使用同一已授权播放器，先核对版本、等metadata并seek至服务端坐标；播放失败/断网保留文字与可恢复动作，不切到外部URL。只有实际就绪的证据才可点击；失权清私有结果/播放器。保留Shell、历史、输入框、右栏、被试/访视卡布局；14/22，长文可用Reading16/28，键盘可达。管理员同源读取，不新增治理总览模块。复杂编辑字幕、完整时间轴编辑器不在首片。

## 7. 验收标准

1. **实执行**：两角色本人新合成视频，真实ASR与真实图像请求有执行器/原件/模型版本及用量，文字不是预写演示结果。无音轨、无语音、视觉不可用独立显示，不冒称全通道完成。
2. **时间/专业质量**：合成中文金标准测CER与专业词保留，语音位置明确estimated；非零起点/晚音轨/切片/VFR/边界词及实际播放器回链有证。若首探针未覆盖某项，不以基础成功替代。
3. **隔离/恢复**：真实来源父链、跨账号/租户拒绝、版本变化、引用伪造、撤权、迟到结果、重复请求/提交未知与刷新恢复，不重复收费/造原件；旧对象/任务/账本保持。
4. **业务验收**：研究者能读懂实际处理范围并点时间核对；管理员不需学习内部hash/任务模型。用户业务签收与生产部署单列。
