# 真实入口与演示数据边界（2026-10-28，本机合成切片）

## 用户可见规则

P003 新登录成功默认进入 P01「我的科研」；`returnTo` 只接受站内已接通入口和有效的 Q02/S11 Study 作用域，外站、演示或未知参数回退 P01。已登录身份页保留「进入我的科研」，也可主动切换账号。注册或找回密码完成后的继续登录入口同样指向 P01；公开注册不自动授予私有 Study。

真实模式与前端演示显式分离。配置本机认证租户且未主动选择「进入前端演示」时，P01 按现有只读聚合接口读取本人数据库记录；Q02、A01、AI01 先从当前服务端会话读取真实姓名、租户和 Study 授权，再给出已接通的本人草稿、知识问答及资产候选入口。入口链接不等于权限授予，具体操作由后端再核验。无会话、无 Study、网络失败分别给出登录、空态、重试，不回退王教授或固定科研数值。AI01 不展示固定问答、虚构来源或尚未执行的 AI 结论，也不自动调用模型。

真实模式的顶栏全局搜索与通知尚无服务端接口，点击只解释未接通，不读取本机演示课题、资产或事件。真实页面头也不从本机演示草稿覆盖标题；K01始终承载真实知识服务，即使浏览器残留显式演示标记，也保持真实会话身份与上述顶栏守门。

所有已登记页面在真实模式下必须明确归入公共静态、认证、已接通、服务端作用域或未接通之一。未接通页显示「此页面的真实数据尚未接通」和返回入口，隐藏其前端固定科研内容；这只是防误认，不代表该页 API 已开发。用户显式进入前端演示时，历史演示保持独立可用，但演示对象不进入真实账号授权链。

## 当前接口与限制

P01 继续使用 `GET /api/my-research/overview`；Q02/A01/AI01 入口使用既有 `GET /api/auth/me` 的当前身份/成员摘要，深链复用各自已有会话与 API。此切片没有新增后端接口、角色、Study 权限、数据库表、付费 AI 或外部邮件投递。K01/S11及已实现的具名作用域页面保持原授权与功能；治理、领域研究、正式EDC、更多AI入口、审批/共享/发布/导出仍未接通，不因守门页而销项。当前仅本机专用合成环境技术验证；生产配置、真实发布、目标环境请求和用户专业验收均未完成。

## 验收口径

原科研人员和管理员从 P003 实际输入账号登录后到 P01，并可在 Q02/A01/AI01 看见自己的会话身份及已授权 Study 入口；恶意 `returnTo` 不离站；匿名不见私有 Study；未接通页不显示演示数值或来源。桌面与手机留截图/录屏，核对浏览器真实 API 请求和无付费模型请求；顶栏搜索/通知与K01残留演示标记也做反例。单元、集成、构建、真实浏览器及独立总评审分别留痕。52路由台账与剩余未接通页面按测试记录公开，不将守门页当作 API 完成。
