# 智能搜索：原文事实与AI推论

用户于2026-11-12要求修补本轮NCCIH盲法推论、WHO授权归属两项问题，并验证新回答的来源一致性。本稿为当前批准修复的执行规格，不恢复其他专项。

## 最小规则

| 内容 | 处理 |
| --- | --- |
| 原文事实 | 模型逐段给出真实来源ID与连续原文短引；后端核对原文属于该来源快照，标为“原文事实”，附简短原句供核对 |
| 一般方法学解释/研究建议 | 明确标“AI推论（非原文结论）”，列出实际依据；不得把推论说成NCCIH/WHO原文结论或已证疗效 |
| 找不到原句的事实段 | 局部不作为事实交付，提示当前选段依据不足；不因一段缺依据阻断其他合格内容，也不自动改称推论以逃过核对 |
| WHO官方/授权归属 | 链接域名可核对来源，不等于转载获授权。无独立授权证明的正向授权结论不交付；非who.int来源不能概称WHO官方网页。否认/未核实授权的准确限制可保留 |
| 伪造来源ID/越权/证据版本变化 | 沿既有控制面拒绝，不靠免责声明放行 |

新输出契约为claims列表：kind=source_fact或ai_inference、text、sourceIds、quotes[{sourceId,text}]；limitations只接收范围字段，用户实际看到的范围说明由系统按真实来源生成，不让自由文本绕过分段依据规则。最多8段，每段不超过1800字符，原句规范化后至少12字符、原长度不超过600字符。每条事实所引来源均需至少一段真实连续原句；推论也必须说明具体来源依据，但原句只支撑前提，不是推论已获证实。句子与原句的语义仍由模型和专业人工核对，确定性短引匹配不能冒称通用语义验真。否认只覆盖对应授权/官方提及，不能给同句另一正向断言开绿灯；缺依据段的原始提议仅保留审计回执，不能因刷新重新放行。

## 兼容和界面

新任务使用v2策略并保存逐段依据回执；既有v1任务、失败和账本原样可读，不重算旧回答。旧快照续问可作为新v2输入，仍不自动外检。仅在原回答Markdown内标识事实/推论及原句，不新增组件、侧栏、按钮或布局。科研人员与管理员一致，无新角色/权限/表；正常Token预留与结算不变。

## 验收

先用原两份证据及合成反例验证：盲法不能混入原文事实、无依据授权不交付、引文不可跨来源/编造、正常否认与合法事实不误拦；历史v1可读/篡改仍拒。再在本机专用合成环境，以原两个账号各一个具名新任务真实读取对应公开网页并生成新回答，逐条核对事实/推论/原句/URL/阅读范围，检查刷新和原账本。无自动重试/充值/新服务；保留全部失败。保持用户专业验收与本机技术执行分别记录。
