## 7. 出错时怎么处理

| 看到的情况 | 你接下来怎么做 | 什么情况需要反馈 |
| --- | --- | --- |
| 席位已满 | 停止注册，交付方核对可用席位 | 已准备足够席位仍提示满，记录时间及原文 |
| 收不到验证邮件 | 到本机体验收件箱按准确邮箱找最新邮件；同邮箱显式重发有等待时间，通常至少60秒 | 收件箱未授权、没有本次邮件或邮件已过期；不要去真实邮箱反复找 |
| 链接无效或已失效 | 核对是否最新邮件；需要时按原页重新申请验证邮件 | 新收到且尚未使用的链接也失败 |
| 创建账号结果尚未确认 | 使用刚设置的密码走原登录入口，核对本人加入状态，不连续再点创建 | 无法登录时保留提示交付方核对，不能仅凭登录失败断言账号未创建 |
| 补充／审核结果待核对 | 按页面提示核对原提交；只有明确提供“重试原提交／重试原审核”时，才使用该按钮 | 一直未确认、原输入消失，或同一操作重复写入 |
| 页面已有未保存内容 | 先保存、核对原操作，或明确选择放弃后再离开；刷新／关闭的防丢失提示可取消 | 审核通过自动跳走并丢掉输入 |
| 业务无权限，但账号仍登录 | 核对当前身份与该项业务授权，不重复注册 | 本人应有权限却打不开，或能看到他人私有内容 |
| 审核列表没有申请 | 检查筛选状态、姓名／邮箱；未创建新申请时为空正常 | A已完成注册仍查不到，或能查到其他租户私有申请 |

1. 打开[公开学术动态](http://127.0.0.1:19501/pages/p011/)，应保留门户导航，显示分类、搜索和真实公开卡片，不进入工作区或要求登录。

3. 切换资讯／研究进展／项目通知／活动；活动可按即将举行、进行中、回顾、取消筛选。输入标题关键词，按Enter或搜索一次生效；没有结果时清空筛选恢复，不显示登录错误。
4. 点击标题，核对全文、来源和活动安排；刷新或复制详情地址到无痕窗口仍可读。“返回动态列表”或浏览器后退应保留筛选；有多页数据时“加载更多”追加、不重复，回详情再返回保留已加载位置。当前真实条目不足一页，多页故障已由受控场景验证。
5. 如有获准公开资料，通过详情“资料与回放”打开；未获准资料不显示，不能因为正文已公开就提供成员资料。仅成员／草稿／撤下／不存在的详情应统一提示“内容不存在、已撤下或尚未公开”，可返回列表；验证私有内容用已知合成样例，不修改真实发布范围。
6. 网络失败应显示重新读取，已输入条件保留。刷新失败可重试或返回列表；页面重新可见会复核最新公开状态。手机320px和浏览器200%检查导航／筛选／长文可读，无横向溢出。
