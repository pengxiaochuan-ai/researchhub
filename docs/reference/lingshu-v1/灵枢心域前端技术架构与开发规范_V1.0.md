# 灵枢心域前端技术架构与开发规范 V1.0

## 一、推荐技术栈

Vue3 + TypeScript + Vite + Pinia + Vue Router

动画：

GSAP + ScrollTrigger + SVG Animation

## 二、首页组件结构

    P00Home

    ├ HeroSection
    ├ ResearchFlowSection
    ├ AssetCycleSection
    ├ CapabilitySection
    ├ CommunitySection
    ├ AIAssistSection
    └ JoinSection

## 三、开发原则

要求：

-   组件化
-   数据驱动
-   高可维护
-   支持扩展

## 四、动画实现

Hero： - 节点出现 - 路径流动 - 呼吸效果

滚动： - Intersection Observer - GSAP ScrollTrigger

## 五、Codex约束

禁止：

-   修改品牌定位
-   自行增加页面模块
-   改变视觉方向
-   增加传统中医元素

允许：

-   性能优化
-   代码重构
-   动画优化
-   响应式优化

## 六、验收标准

-   页面与设计稿高度一致
-   字体清晰
-   布局稳定
-   动画流畅
-   代码可维护
