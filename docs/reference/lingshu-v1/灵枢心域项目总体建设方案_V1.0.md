# 灵枢心域项目总体建设方案 V1.0

## 一、项目定位

灵枢心域定位为：

> 针灸防治情志病领域学术科研共同体 + AI驱动科研平台

平台连接领域知识、科研证据、研究项目、专家网络和科研资产，推动科研能力持续积累。

## 二、建设目标

支持： - 科研问题发现 - 研究课题组织 - 研究方案管理 - 科研协作 -
证据沉淀 - 科研资产积累

形成：

> 每一次研究，都为下一次研究积累证据、资产与知识。

## 三、核心建设内容

### Research Hub

围绕研究领域建立科研空间：

-   研究方向
-   科学问题
-   研究课题
-   研究方案
-   研究成果
-   科研资产

### 科研资产体系

沉淀：

-   文献资产
-   证据资产
-   数据资产
-   方法资产
-   成果资产

### 学术科研共同体

连接：

-   临床医生
-   科研人员
-   青年研究者
-   多中心团队
-   科研机构

### AI辅助科研

用于：

-   文献整理
-   知识检索
-   方案辅助
-   科研文本辅助

原则：

AI Assistant，Human Accountable。
