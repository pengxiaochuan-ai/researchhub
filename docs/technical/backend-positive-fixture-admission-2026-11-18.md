# 独立部署正向验收：准确增量提案

2026-11-18用户已批准有限正向夹具范围，按下列准确总量实施；下文原有阻断和取舍保留为历史背景。承接已批准的独立部署演练，不涉及生产、旧服务、历史记录、模型调用、Token额度或外部邮件。

## 已有边界与实际阻断

已批准最多4个合成账号、1个Study、1知识库/资料、1任务、1报告草稿和1资产候选。当前已在独立新库初始化3个账号、1个只读角色和1个Study；原数据库、原Study不作为这些新对象的替代来源。

新的报告AI材料用途约束要求：原生T17读取器确认分析依据当前有效、报告固定版已审核并仅在私有Study内启用、登记资产固定版已审核。普通草稿不能满足此条件；不能直接把数据库状态写成released/approved充数。旧报告只读不复制到新库。

资产复制/应用的真实正向验证还会生成新的目标草稿，不能把它们悄悄计入原1份来源报告或伪造已有目标。

## 建议一次性增加的准确范围

继续仅限本轮新独立合成租户、现有单个Study和已批准4账号上限，由本轮合成管理员操作，不新增账号或角色，不增加成员权限。

| 对象或操作 | 本轮总上限与限定 |
| --- | --- |
| 合成受试者与正式结构CRF | 3名纯合成受试者；1个方案固定版、1份执行政策、1个基线访视计划、1个表单固定版；每人最多1次合成入组、1个访视、1份CRF及1次显式更正。全部明确合成，不接临床数据 |
| 原生分析依据 | 1个分析计划及其审核、1个数据快照及必要质控评价、1次免费确定性描述统计运行及人工确认；不执行LLM、不编造数值 |
| 来源报告 | 沿原1份报告额度，通过原生T17生成、内部审核、仅本机私有Study内启用；不直接改数据库状态、不生成对外发布或导出 |
| 来源资产候选 | 原上限1→最多2份：1份来自上述真实方法报告，1份本人合成方案模板。每份最多2版；允许提交、退回/修订、内部审核，保持私有未公开 |
| 复用目标 | 最多2份本人新草稿：1份复制目标、1份方案应用目标；均在同一现有Study，不新增第二个Study。复制目标本身也是已登记资产候选，不能算作未登记草稿 |
| 讨论与附件 | 最多2条评论（其中1条回复）；最多1份不超过4KiB的纯合成Markdown附件。临时上传、引用/撤回及关联事件只服务上述具名对象 |
| 材料依据与本人AI许可 | 上述报告固定版最多3条材料审核事件、3条本人用途许可事件，验证批准→撤销→显式再授权且不延长首次7天窗口；仅免费检索/重验，不发送模型 |
| 反例 | 使用同批对象的错误租户/父对象/版本/authVersion、无创建权、失效用途、重复请求，以及仅新库内可回滚的故障/并发事务；不更改旧夹具。失败与回滚保留证据，不清理账本冒充初次成功 |

数量核算：上述范围合计最多5份 `research_artifact`（1份来源方法报告＋2份来源资产＋1份已登记复制资产＋1份方案应用草稿），其中最多3份 `asset_registry`（2份来源＋1份复制）。全部计入已批准的同一批总量，不另叠加。

账号注册/找回/邀请仍沿原最多2个challenge、1次邀请；已创建3账号，公开注册最多再增加1个。科研只读角色及其邀请不扩大。所有成功原生操作、对象ID、版本和事件单独留manifest；发生未列明的新对象、权限或费用时再停。
