# F07 · 个人记录与固定来源

日期：2026-11-20。沿已确认K01最小差异实施；仅本轮owned独立合成环境，生产未发布。

## 实现与保留的边界

沿原个人KnowledgeBase、KnowledgeDoc及版本/审核/检索，不新增第二个个人库或结构化指导系统。新建文档默认普通文档，可选择阅读笔记、研究想法、指导记录；指导人、日期、研究及讨论行动均由本人填写，不产生专家确认或医学事实。

新建记录可选当前库已有材料。先经原GET授权读取实际版本，计算正文SHA256并生成既有K01固定知识资料链接；再沿原POST仅创建空白文档。模板内容绑定真实返回docId、库及账号/authVersion/组/项目，唯一授权GET loader消费后进入未保存正文。用户明确保存才PATCH，保留原baseVersion/CAS、审核及全文/AI检索门。本人私库所有者沿原权限审核；未审核草稿不进入检索。

编辑区“关联资料”只识别当前scope内严格合法的站内固定版本链接；进入时沿原未保存确认，取消/Esc保留稿件。原资料重新核权，版本/hash不符拒绝，不回退latest。普通Markdown和模型自带链接的不可点击策略不扩展。

## AI主动采纳代码与未验项

“整理到当前文档”只对当前本人私有可写、正处编辑模式的文档开放。点击后重新读取当前会话回答及每个固定来源，必须全为current且内容/引用一致；结束再核账号、authVersion、scope、库、docId、版本和可写状态。使用最新草稿追加，不能覆盖并行输入、自动保存、自动审核或触发模型。

模型正文进入编辑器前转惰性Markdown文字，图片、HTML和自带URL不自动执行；只有已核来源元数据可生成站内固定资料链接。过期、撤权、文档/身份切换及超长正文保原稿。

当前独立环境无合法真实AI回答/问答准入。用户已明确确认：真实采纳并入正在进行的K01问答验收，单列待验，不借用预算或自动新增调用。免费纯函数/组件契约只证明代码，不证明真实模型、生产服务或AI业务结果已完成。
