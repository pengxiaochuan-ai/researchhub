# G02 生产接口修复

独立 ResearchHub 生产库只读核验确认邀请表存在，邮件模式为 disabled，`rh_hub_asset` 资产审核所需对象缺失。

生产后端注册现有用量对账控制器，并复用原账本服务和租户授权。邮件关闭时，邀请列表和研究上下文继续通过原研究权限读取，邮件与邀请写操作维持当前关闭状态。

资产审核需要对独立 researchhub 库另行安装 `server/hub-assets/migration.mjs` 和配套固定报告迁移所生成的 DDL。发布这批代码不执行建表及授权。应先验证前置对象、实际 owner/app 角色和受管 schema 指纹，并在合成库演练后单独批准生产执行。
