# E02论文详情：检索到阅读性能检查

2026-11-18；用户要求检查E02加载性能。结论：当前三个真实来源样例的两轮本机测试未发现需要修补的详情性能瓶颈，本轮不修改生产代码、查询、权限或页面布局。

## 范围与方法

仅现有专用合成环境，部署rh-kb-local-b0e2af9d、主PID99513、19501–19507七服务。匿名与原admin分别通过真实Chrome，在E01列表点击真实论文标题进入E02。三篇各测两轮，共12次页面导航；另测12次真实详情HTTP。选择公开列表前20项中的首篇PMC、正文最长PMC及首篇工作簿来源，并非全库最大论文或随机统计样本。

计时从点击E01标题到E02真实题名及已获准正文标题可见；正文、表格在同次React提交中渲染。另记录详情响应耗时/大小、正文字符、表格数、DOM数量、≥50ms长任务、页面异常及横向溢出。脚本随后等待networkidle用于截图，但未单独保存该时长，因此本报告不将其当作完整资源完成或15秒网络尾部专项结论。

两轮是同一代码和运行环境的重复测量，文件名before/repeat不是修前/修后。本次没有性能代码变更。

## 后端与前端诊断

E02走publications/:id精确读取，不调用E01全列表统计。PMC详情读取当前获准文章版本、组件与附件决定；成员接口保留当前身份/访问核验，匿名按原401/403规则读取公开接口。管理员浏览器额外耗时包含/auth/me、成员详情核验及身份变化时的取消/重读，不能将整段差值都归因于数据库。

未发现逐表或逐正文块的独立请求/N+1。本文实测不支持引入详情缓存、跳过当前授权、删除身份重核或改为分段加载；保留现有原布局、16/28阅读字号、表格局部滚动和来源追溯。
