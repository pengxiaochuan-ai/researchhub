# 通用合成科研流程验收输入与独立数值依据

这是一组待执行的纯合成输入，不是已经建立的真实对象或通过的验收。它为当前用户确认的现场录入、H5自填、CSV导入和首项描述统计提供同一对照，后续T13/T15/T16/T18使用时必须映射到目标环境真实创建的Subject、访视、正式答卷修订及快照，不能把这里的逻辑case当数据库ID。

新发布通用表单包含必填数值 `value`、选填数值 `optional_value`、必填布尔 `completed`；不配置临床评分。三个来源各提交一名不同合成对象的基线记录。选填字段缺省仍为缺失，数值0与布尔false都必须保存为真实值。CSV是导入映射模板，确认前应替换成当前已建档编号并明确访视/表单版本，不猜关联、不整批重复导入其他来源。

`oracle.json` 由标准库脚本生成预期统计及一次更正后的预期结果，采用样本标准差、基线每被试一条当前有效答卷，不混入后续访视。数值均由Python确定性计算，不由LLM补算。还需分别测试空样本、单样本、全缺失和字段类型错误；这些规则不等于方法worker已经实现或研究数据已放行。更正后必须重新审阅、形成新快照和新运行，保留旧快照与旧数值及其失效状态，不能原地重写历史报告。

生成命令：`python3 scripts/research-study-synthetic-oracle.py`。专业临床规则、真实材料和生产验收仍不在此合成材料中。
