## 已打通流程

`P002 → 登录页面 → 进入前端演示 → Q02 → Q01保存课题 → 对应S07方案 → S08任务 / S09访视 → S05核对 → S10产出 → A02本机资产 → 复用到另一课题方案`

课题、方案和资产使用各自标识。方案继承新课题名称与PICO，保存后可刷新恢复；复用保留sourceAssetId/sourceVersion与来源产出。新对象不会变成历史固定示例。

公共搜索可以搜索本机课题、资产和现有页面；通知显示本机操作记录；用户菜单提供资料、登录与退出演示入口。帮助与工作区导航可用，手机科研页侧栏按需展开。注册不保存密码，演示角色不授予真实权限。

## 数据与服务边界

当前数据只保存在当前浏览器，不能跨设备同步，也不是正式多用户协作服务。本机操作日志可被浏览器修改，不提供不可篡改审计。真实账号验证、短信/邮箱、邀请、权限、伦理批准、AI推理、统计计算、文件托管、资产公开发布与跨设备同步仍待后端。

指南/教材内容和发起专家机构名单待确认，不虚构记录。注册表单“检查资料”不等于注册成功；科研产出的“已复核”只是演示标记，不等同专家或伦理审批。

主要适配位置：`src/route-context.js`（导航上下文）、`src/demo-research-store.js`（本机业务存储与版本）、`src/platform-frontend.js`（公共事件）、`pages/shared/PublicPages.jsx`（门户）、`pages/shared/WorkflowPages.jsx`（对象流程）。正式服务接入时保持页面契约，替换演示读写与认证流程。
