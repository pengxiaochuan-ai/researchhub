# G02 管理与治理总览入口校正 · 本机技术记录

日期：2026-11-01。范围仅 G02 真实模式布局职责和来源审核入口；其他页面、审核 API、决定、数据库、旧服务、模型调用与发布均未改。用户随后批准顶部导航、页头占位和窄屏三项局部修正。

## 依据与结果

- 用户确认：保留已确认的「管理与治理」总览；来源审核只作为其中子功能。其他页面接后端不得擅自变更前端交互，必要调整先提交建议并获确认。
- 原因：真实模式之前直接返回 `HubSourceWorkbench`，覆盖 G02 母版；直接恢复旧 JSX 又会露出固定 2024 演示统计。
- 实施：真实模式沿用原总览的标题、治理导航、六张指标卡及三行卡片结构；无真实汇总的内容显示 `—／未接通` 或明确空态；「快捷操作」进入来源审核，返回总览；审核组件改为可嵌入，不改其提交与权限逻辑。
- 浏览器：`node scripts/g02-governance-entry-browser.mjs` 在 1440×900 管理员、390×844 科研人员真实登录且身份核验完成后，验证入口、返回、原六卡、无固定 2024 数据；管理员 PMC 20 候选真实读取，`review-batches` 网络响应分别为 200/403。首轮 RED 失败于缺「管理与治理」标题，修补后 GREEN。PNG/WebM 与结果 JSON 位于 `/Users/mac/aisciencesys/docs/test/evidence/2026-11-01-researchhub-g02-governance/672aa920/`。
- 自动检查：`node --test tests/hub-source-admin-ui.test.mjs tests/real-mode-route.test.mjs`：5/5；`pnpm run build`：通过（既有大包体积提示）。

## 获批修正及复测

- 测试先行：扩展 `scripts/g02-governance-entry-browser.mjs` 后，RED 首先失败于缺少「下载治理报告（未接通）」原槽位；修补后 GREEN。
- G02 真实模式顶部「数据治理」与快捷操作均到 `/pages/g02/?view=source-review`，顶部「总览」及页内返回去掉该视图参数。进入审核仍由原服务端权限守门；G03 显式演示模式的「数据治理」仍到 G05，未更改共同导航数组及其他页面目标。
- 页头保留原三个动作槽位；「知识库治理」仍链接 K01，报告与日期显示未接通并使用原生 `disabled`，不发下载或伪造日期。仅 G02 真实模式在手机宽度让导航可横向滚动、390px 六指标两列、320px 六指标单列，三行卡片变单列；桌面栏位顺序及卡片横坐标保持原母版。原图与本轮 1440 截图同视口目视比较，无正文结构重排；页头动作是用户已批准的差异。
- 真实 Chrome：1440×900 管理员、390×844 科研人员、320×740 管理员均通过顶部与快捷入口、返回、页头禁用、六指标真实空态及根无横向溢出。390/320 卡片宽分别 327/257px，治理标签可滚动；320px 审核候选选择框 x=49、宽 207px，仍在视口内。管理员两次读取 20 个 PMC 候选及 200，研究人员审核请求 403，控制台 `pageerror` 为空。G03 演示导航仍到 G05；从 G02 来源审核进入 K01 不携带 `view=source-review`。截图、WebM、网络与尺寸结果在 `/Users/mac/aisciencesys/docs/test/evidence/2026-11-01-researchhub-g02-governance/27c0cf9d/`。
- 独立只读评审查出共享 `navActions` 分支误用未定义 `targetContext`，可能令 O02「形成研究课题」失效；真实 Chrome 先复现停在 O02（RED），再恢复该分支原单参数导航，复测到 Q01（GREEN）。此修正不改变 O02 交互目标。最终独立只读复核确认该 P1 已关闭，当前 G02 范围未发现剩余 P0/P1/P2；审核表单其他窄屏控件未逐件测量，桌面同视口比较以截图目视为主，不把这两项称为全面专业验收。
- 相关 5 项 Node 测试、`pnpm run build`、`git diff --check` 均通过；构建仍有既有大包体积提示。本轮无数据库、审核决定或付费模型写入。仅本机技术验收，不代表专业用户完成时间或生产发布通过。
