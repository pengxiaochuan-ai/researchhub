- `node --test server/hub-sources/*.test.mjs scripts/hub-agent-contract.test.mjs`：最终重启后 30/30 通过。覆盖公开空态、匿名/越权审核、原有论文来源兼容、带类型引用、回滚模拟审核/撤回/换版（包括 v2 双用途批准仍拒绝）、实际 HTTP 的双账号无来源检索。
- `npm run build`：通过，只有既有大块体积警告。
- 真实 Chrome/Playwright 录屏和截图：[最终结果](../../../docs/test/evidence/2026-10-31-h0-external-projection/browser-973219cd/result.json)、[桌面](../../../docs/test/evidence/2026-10-31-h0-external-projection/browser-973219cd/h01-desktop-unreviewed.png)、[390px](../../../docs/test/evidence/2026-10-31-h0-external-projection/browser-973219cd/h01-mobile-unreviewed.png)。页面未露出未审编号与版权原文字样，未有控制台异常；两个视口都从真实后端收到 200 + 空态。

## 未通过与未验项

- 390px 时公共 Shell 仍占去侧栏宽度，H01 主内容仅约 **154px**；虽无横向滚动，字体逐字换行，移动端体验不合格。本轮不扩改公共 Shell，需另行确认公共布局范围后修复并在 320px/200% 缩放复验。
- 无真实权利依据和管理员持久批准，不能在浏览器做“已准来源显示/撤回”正例，也不能调用模型证明真实 AI 回答。合成回滚测试只证明代码契约；最终业务验收待管理员逐份核对、授权与专业用户确认。
