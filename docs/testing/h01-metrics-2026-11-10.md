## 已发现而未隐瞒的边界

1. 历史`server/hub-sources/external-visible.test.mjs`的5项均前置失败，日志`source-projection-tests.log`。该旧夹具固定authVersion=0，当前两合成账号实际authVersion=5，`assertCurrentReviewer`拒绝旧身份；不是本轮统计返回失败。未改身份/审核权限或旧夹具来凑全绿，后续应按现行审核契约专门刷新。具体5项：five sources stay private without current per-purpose approval；rollback-only review opens metadata by purpose, then revoke immediately closes it；approved standard and guideline never appear in clinical registry list or detail；guidance approval, revocation and new version each affect H06 visibility；a new external file version invalidates prior display and AI decisions。
2. 原KPI前两卡被公共装饰器标role=link，但真实模式的findPageRule不处理它们，Enter没有跳转；本轮未新增/改变该交互。验证注册明细使用既有领域导航，不谎称卡片直达已通过。此为后续H01交互待办，不切换去改全局路由。
3. 网络5xx/超时、在途多次重试的浏览器故障注入未做；单元验证失败/null/0/非法数值，源码epoch作废旧响应。未知Hub404已实测，不等价上述网络故障。
4. 不声明全站功能完成、生产启用、科学范围纳入或用户最终验收；当前实现、环境和实际请求已有证据，最终产品签认由用户完成。未测320px/原生200%缩放或完整WCAG。
