- 逐篇题名表明首批含抑郁症随机试验，也含偏离目标的偏头痛、腰痛、PCOS 等研究。它们只是检索候选，主题相关性、文章许可及第三方图表/附件权利均须管理员逐篇核验，不能因关键词命中就批量放行。
