# 岐研 Navigation & Page Header Standard v1.0

状态：Frozen

## 四层页面头

- L0 Global Topbar：品牌、Global Search、通知和用户身份，所有页面 100% 一致。
- L1 Context Breadcrumb：只表达信息架构位置，最多四层。
- L2 Page Header：只放标题、说明、上下文元数据和页面级操作。
- L3 Context Navigation：Hub、Study、治理等上下文内部导航；不需要时不显示。
- L4 Page Content：业务内容和 Supporting Rail。

## Global Topbar

- 品牌固定为 Logo、岐研、中医临床研究智能平台；英文仅作为弱签名。
- 搜索固定为“搜索课题、文献、研究问题或数据...”。
- 身份固定为王教授 / 课题负责人，不随上下文变化。

## Breadcrumb

模型：`一级工作空间 > 当前上下文 > 当前对象 > 当前页面`。

- P01 不显示 Breadcrumb。
- H01：`领域研究 > 针灸治疗情志病`。
- C01：`领域研究 > 针灸治疗情志病`。页名是临床注册，研究列表、研究分布地图和趋势分析在页内切换。
- C03：`领域研究 > 针灸治疗情志病 > 临床注册 > 试验详情`。
- T01：`领域研究 > 针灸治疗情志病`。页名是研究团队。
- T02：`领域研究 > 针灸治疗情志病 > 研究团队 > 团队详情`。
- R01：`领域研究 > 针灸治疗情志病`。页名是研究者。
- R02：`领域研究 > 针灸治疗情志病 > 研究者 > 研究者详情`。
- E01：`领域研究 > 针灸治疗情志病`。页名是研究论文。页头操作是保存检索、检索历史、导出结果。
- E02：`领域研究 > 针灸治疗情志病 > 研究论文 > 论文详情`。
- O01：`领域研究 > 针灸治疗情志病 > 研究机会`。
- O02：`领域研究 > 针灸治疗情志病 > 研究机会 > OP-2026-017`。
- Q01：`领域研究 > 针灸治疗情志病 > 研究机会 > 研究课题`。
- A01：`科研资产`；A02：`科研资产 > AS-2026-018`。
- G02：`管理与治理`，不得添加“我的科研”。

## Context Navigation

### Research Hub

`总览 / 临床注册 / 研究论文 / 指南与教材 / 研究团队 / 研究者 / 研究机会 / 科研资产 / 相关研究`，右侧固定“＋ 新建研究”。左侧一级导航始终高亮“领域研究”。

### Study Workspace

`概览 / 研究设计 / 研究执行 / 数据与质量 / 研究分析 / 科研产出 / 科研资产 / 团队与设置`。

### Management & Governance

`总览 / 伦理合规 / 数据治理 / 研究质量 / 用户与权限 / 多中心管理 / 审计日志 / 系统配置`。

## Page Header 内容限制

左侧仅允许 Breadcrumb、Page Title、Page Description / Context Metadata；右侧仅允许 Secondary Actions 和 Primary Action。

禁止：装饰插画、山水、书法 slogan、不同高度的大 Banner、抢占主体的英文胶囊。Concept Label 可以弱化显示。

页头与顶栏、侧栏的贴合方式，以及正文左缘如何与标题卡片对齐，见 `page-layout-practice-v1.0.md`。
