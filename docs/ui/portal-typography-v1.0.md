## 目的与边界

开放门户服务于首次接触产品的临床医生、科研人员及机构用户，应在普通笔记本和手机上直接读懂价值、步骤与参与方式。科研工作区的 14px Body / 12px Caption 适合密集操作，不应直接移作门户阅读规则。

本规范补充 P002 与后续开放门户的排版要求，不修改 Frozen 工作区 Token、品牌、七屏顺序、正文内容或路由。P002 原稿仍是构图、素材与业务内容依据；出现文字难读、裁切或图片未呈现时，记录当前实测问题并在保持构图的前提下修正。历史“已验收”记录不豁免新发现的问题。

## 响应式、长度与缩放

- 字体沿用 `PingFang SC / Microsoft YaHei / system-ui / sans-serif`；不为此次审查引入远程字体。正文行高约 1.5–1.75，中文阅读行长以约 20–35 字为起点，用实际段落核验，不作为硬截断长度。
- 排版角色集中维护于 `typography.css`（P002）或门户公共作用域；后续修改须收敛同一角色的重复媒体查询。使用相对字号及有上下限的 `clamp()` 时，尊重用户默认字体，避免仅靠 `vw` 让文字随小屏无限缩小。
- 空间不够时先折行、降低列数、调整留白，再评估内容高度；不能将同级长标题单独压成 17px，也不能用 `white-space: nowrap` 配合 `overflow: hidden` 隐藏文字。
- 320px 宽度下，AI 工具等密集网格应能改为单列或允许子项收缩/换行。必须检查区块及卡片内部溢出；根元素无横向滚动条不是通过证据。
- 长页面以内容自然高度为主。1366×768 等矮屏允许纵向滚动，不为“七屏各占一屏”缩字。手机人物卡按内容与图片比例控制高度，避免五张大卡连续形成过长的空白滚动。
- 图示中的关键标签优先提供对应 HTML 文本；位图不能计入 DOM 字号扫描，需按最终渲染尺寸另看可读性。若更换为独立标签，保留原图示语义及命中区域。

## 对比度、控件与动效

- 普通文字目标不低于 4.5:1；符合大字定义的文字不低于 3:1。占位文字、标签及 hover/focus 状态也须检查；图片、渐变和透明层按实际合成背景核验，不能只比较 CSS 前景色与白色。
- 浅色工作区 Token 不自动适用于门户。`#8B98AC` 对白色约 2.92:1；需要阅读的说明改选满足要求的语义颜色，而非降低透明度。
- 项目触控目标建议至少 44×44px。图标、飞轮节点、菜单与按钮须有可识别名称及键盘焦点；44px 是项目目标，不冒称 WCAG AA 的统一最小尺寸。
- 持续动画提供减少动态效果的静态可读状态，不让文字内容随自动轮播丢失。浅色发光图示不能替代正文说明。
