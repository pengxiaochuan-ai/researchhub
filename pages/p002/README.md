# 灵枢心域 P00 首页 V1.7

基于用户提供的 7 张设计图与《Codex开发说明书 V1.0》对齐。零依赖原生 HTML / CSS / JavaScript。

启动：在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，访问 http://127.0.0.1:4173。

顺序：首屏、科研流程、资产、共同体、能力模型、适配人群、加入入口。图片决定视觉及顺序，说明书决定动画、响应式与专家责任原则。

内容位于 content.js，行为位于 app.js，样式与断点位于 styles.css。图示、照片、标志采用原设计图精确窗口；标题、说明、导航、卡片和表单为原生 HTML。3 张背景经图像编辑清除 UI，存在局部补全差异。

交互：飞轮与共同体节点支持 Tab / Enter / Space；五步科研流程支持悬停、焦点和点击；身份选择带入加入弹窗；搜索定位首页相关模块；意向草稿仅保存在当前浏览器，可下载 JSON。登录、注册与预约尚未接入平台 API。

动画：飞轮轻浮动与光环、流程状态高亮、资产序列入场、网络节点浮动、AI 与专家协同分层显现。屏外暂停持续动画，prefers-reduced-motion 下停用动画和过渡。

验证：1920×1200 逐屏对比，1440×900、1366×768、390×844 无横向溢出；浏览器交互与 JS 语法检查通过。详细证据见 design-qa.md。本版本完成视觉对齐验收，未声称逐像素相同。

V1.3 背景修正：首屏飞轮和第二屏 Research Hub 改为独立透明 PNG；第二屏照片、底部波纹及背景遮罩全部移除；首屏只保留一张科研照片背景，飞轮右移留出标题间距。

V1.3：新增 1440×900 紧凑桌面排版；逐屏字体复核、增强标题字重、放大 AI 说明并改善按钮与小字对比度。详细记录位于交付目录的 TYPOGRAPHY_REVIEW.md。

V1.4：将普通 H2 调整为 1440 下 40px / 600，共同体 44px，CTA 48px；1920 下对应 48 / 52 / 56px。字号策略集中在 typography.css。

V1.6：节点说明改为常驻详情卡；点击坐标校准、取消鼠标椭圆框；资产标题行和科研能力三卡基线统一。新增 interaction-layout.css。飞轮光点采用同步 SVG 椭圆轨道。详细证据见交付目录 INTERACTION_REVIEW.md。

V1.7：鼠标移入飞轮或共同体节点即可切换说明；离开后保留最后说明。继续支持点击与键盘焦点查看；相同节点不重复触发详情更新。
