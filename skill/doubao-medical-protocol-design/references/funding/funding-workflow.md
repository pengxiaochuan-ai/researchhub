# 医学科研基金与项目申报辅助

用于基金选题论证、资助方向匹配、申请提纲、立项依据与研究内容梳理、已有申请书修改、评审意见分析、经费说明及相关申报材料。先按本轮问题工作，正式材料交 `word`；简单咨询、方向比较和单独提纲可直接回答。

## 1. 先明确申报目标与可用材料

先识别本轮是国家自然科学基金（国自然）、具体省市/自治区等地区的自然科学基金，还是其他科研项目、医院或院内基金，再确定资助方全称、申报地区、年度、项目类别和用户要解决的部分。用户说“内自然”等地方简称时，根据其通知、模板或所在地区确认具体指向；上下文已明确的直接沿用。仅说“自然基金”或简称仍无法定位时，简洁询问基金全称或申报地区，同时可先整理研究问题和已有基础。

复用已有的指南、模板、原稿、评审意见、前期论文/预实验和团队条件。尚未选基金时，先结合研究方向、研究者阶段、所在地区和实际条件比较适合的资助类型。

按已确认的资助类型读取 [国内基金格式与年度要求](china-application-format.md)，取得该资助方、目标申报年度和本类别的官方指南与申请书要求。国自然使用基金委要求；地方自然科学基金使用对应地区主管部门或基金管理机构要求；医院、院内及其他项目使用各自发布单位的要求。基金资助目标、指南方向和申请代码按实际官方内容匹配；将本项目为何适合申报该方向说具体。篇幅与结构服务于科学问题和相应官方模板。

基金任务围绕“为什么值得资助、拟解决什么、凭什么能完成”组织；需要完善研究方法时，再读取 [方案设计分支](../protocols/protocol-design-workflow.md) 的相关模块。学位开题、一般研究方案和论文按各自分支处理。

## 2. 形成有证据支撑的申报主线

- **凝练问题与假设。** 从具体医学或基础研究问题出发，说明已知进展、尚未解决的关键缺口、本项目的假设及其可检验性。区分基础科学问题、临床研究问题与拟开发的技术目标，结合资助方向选择合适表达。
- **说明项目价值。** 用直接相关文献和实际观察说明为什么现在值得研究，核心矛盾在哪里，本项目可以推进哪一步认识或方法。创新点落到具体机制、技术、方法或应用证据；已有方案的差别与本项目的贡献说清楚。
- **把目标落到研究内容。** 每项内容说明要回答的问题、拟用的对象与方法、关键指标、判定方式及与其他内容的关系。预期结果如何支持或修正假设要能解释，技术路线图与文字一致。根据实际科学逻辑分节。
- **把可行性落到真实基础。** 团队论文、预实验、队列、样本、平台和合作条件以已有资料为依据。说明它们具体支撑哪一项任务，关键方法是否掌握，招募或材料获取是否可行；对影响完成的核心困难给出可执行的替代路径。
- **把工作安排落到任务。** 研究期限、年度计划、阶段成果、人员分工与研究内容衔接。经费说明围绕任务和实际数量、单价或测算依据；是否编制预算、科目与额度按资助方要求处理。

已完成的研究基础、正在开展的工作和未来计划分别表述。缺少的预实验结果、病例数、伦理信息、设备条件、合作承诺和经费数据保留待补位置，先完成已有资料能支撑的内容。

## 3. 按本轮材料选择处理方式

| 用户需求 | 本轮重点 |
|---|---|
| 想选方向、判断能否报某类基金 | 比较项目与资助目标的契合、科学价值、研究基础和主要可行性，给聚焦建议与需要补强的实质内容 |
| 形成申请思路或提纲 | 给出项目主线、各章节要回答的问题、拟采用的证据与前期材料，便于研究者继续完善 |
| 整理申请材料或完善已有草稿 | 以研究者的原创思路和真实材料为基础，按目标项目允许的辅助范围组织论证、修改正文和编排 Word 工作稿 |
| 只改立项依据、研究内容、创新点、基础或经费说明 | 完成指定部分，并处理与它直接相关的目标、方法、依据或数字；已有有效内容保留 |
| 改本子或处理基金评审意见 | 对照原稿和实际评审意见，先解决科学问题、证据与设计衔接，再处理结构和语言；按需要交付修改稿及简洁修改说明 |
| 申报答辩或汇报 | 按指南与评审关注点提炼问题、创新、基础、路线和关键回应；课件交 `ppt` |
| 基金进展、结题或成果材料 | 结合任务书、截至时点和实际完成情况，按资助方报告模板组织；需要时复用科研报告写作指导 |

改稿意见应定位到具体段落及其对申报论证的影响，给能落实的修改；基金评议采用该项目的资助目标和实际评审要求。用户提供范本时参考章节功能与表达，当前申请的事实、数据和论证来自本项目。

## 4. 检索、格式与交付

基金通知、申请指南、填写说明及模板优先用可直接调用的 `general_search` 定位资助机构官网，读取相关正文与附件；项目管理要求与医学证据分别检索。医学指南/说明书和论文继续使用 [共享工具顺序](../tool-routing.md)，独立查询尽量同步并行；取得足以支持本轮申报主线的核心证据后继续写作。立项依据等多来源学术证据综合沿用 [引用与题录规则](../related-research-and-citations.md)，纯格式整理或局部润色复用已有来源。

资助方的年度模板决定章节、字段、篇幅和版式。国自然等对生成式 AI 使用有专门要求的项目，按 [对应年度规则](china-application-format.md) 开展研究者主导的论证与材料协作，交付中说明材料用途和需要研究者完善的内容。

将正文或工作稿、官方模板与版本、标题/字段映射、技术路线图表、国标引文编号及真实 URL 一次交给 `word`。使用基金申请文书体例；引用原生上标、每条参考文献末尾“（查看来源）”超链接等按 [共同交付规则](../output-and-feishu-qa.md) 传递。模板规定的格式优先于通用封面、目录、字号和页码默认值。

正文内的年度安排、任务分工和经费表随 Word 制作；独立可编辑的预算测算、任务进度或材料汇总表交 `sheet`。最后使用 `present_files` 交付文件，简要说明本轮完成的内容、采用的模板/年度与关键待补材料。
