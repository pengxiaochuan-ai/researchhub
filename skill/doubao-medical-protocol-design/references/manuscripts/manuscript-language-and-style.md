# 医学论文语言与风格润色

用于论文或章节的语言润色、学术翻译、精简和表达一致性修改，与 `research-writing-and-editing.md` 配合使用。先明确稿件类型、章节功能、语言、目标期刊和用户指定范围，复用本轮已读材料与既定要求。

## 1. 先处理论证，再处理措辞

按“章节功能 → 段落逻辑 → 主张与证据 → 句法和术语”推进。先判断一段话要完成什么、前后怎样衔接，再改得清楚、准确、自然；局部措辞的流畅不能掩盖结构或证据问题。

- **结构层**：核对研究问题、目的、方法、主要发现和结论是否对应；背景由领域认识聚焦到具体问题，讨论从本研究发现展开到有依据的解释与意义。
- **段落层**：每段围绕一个中心论点，按需要连接提出问题、说明证据、比较解释、交代限制与承接下一段。可重排句子、合并重复内容或拆开混杂主题，保留用户要求的章节主线。
- **证据层**：重要判断说明依据及其适用范围。区分观察结果、作者解释和延伸意义；引用说明本研究支持、采用、比较或调整了什么，公平呈现既往工作与实际研究缺口。
- **句子层**：在上述关系清楚后调整主谓、指代、信息顺序、术语和修饰范围。每句主干清楚，长句按逻辑关系拆分，避免碎句、悬垂从句和仅用逗号连接独立句。

## 2. 按章节完成不同任务

| 部分 | 润色重点 |
|---|---|
| 题名 | 让研究对象、关键问题、方法或情境具体且便于检索，术语准确，贡献范围与证据一致。长度按稿约。 |
| 摘要 | 压缩为问题与缺口、实际方法、关键发现及有边界的意义；结构式摘要按栏目组织。优先保留决定研究解释的结果和必要数值，与正文一致。 |
| 引言 | 交代问题为何重要、已有认识、仍未解决的具体缺口，以及本研究要回答什么和怎样切入。删去与研究问题无关的历史铺陈，结果细节留在相应章节。 |
| 方法 | 使设计、对象或数据来源、处理流程、测量、结局与统计描述清晰可复现；已有方案或方法可准确引用。遇到关键条件缺失时指出具体信息，不能用“常规方法”等概括替代，也不补写未实施的步骤。 |
| 结果 | 围绕实际分析或实验说明在什么对象、条件和时点观察到什么，以必要数值、效应量及图表支撑。段落有明确发现，避免逐格复述表图；解释以直接由结果支持的范围为度。 |
| 讨论 | 解释主要发现的意义，比较一致与冲突证据，分析可能原因及替代解释，再说明限制、适用范围和后续问题。局限应对应具体判断，避免换词重放全部结果或用泛泛展望收尾。 |
| 结论 | 回应研究目的，提炼主要贡献、决定性依据及可支持的意义；与已呈现结果和讨论衔接，保持研究范围。 |
| 综述正文 | 以主题、机制、方法或争议组织综合论证，比较来源间的一致性、差异与边界；单篇摘要作为素材，引用服务于当前论点。 |

不同论文类型按自身功能调整，用户大纲与期刊栏目优先。上述写法是组织线索，不要求所有章节使用同一段数、句式或模板。

## 3. 保留科学含义和定量信息

保留样本、人群、分组、终点、时间窗、分母、数值、单位和引用对应。移动段落或调整展示编号时，原始来源及其支持的主张保持可追溯。

- 效应量、绝对与相对变化、置信区间、p 值、区间端点及不等号按原数据准确呈现，核对其对应的比较组和结局；语句精简不能丢掉决定解释的限定。
- 保持关联、预测、机制、因果和临床获益的区别。例如观察到关联时保留关联表述，不能因语言强化而写成已证实因果。
- 根据实际证据选择“表明”“提示”“可能”等报告动词和情态措辞，保留否定、程度、条件与不确定性；明确证据支持时也不机械削弱结论。
- “首次”“最佳”“证明”等措辞与实际核验范围匹配；已有工作、创新点、普遍适用性和临床外推均有具体依据。
- 发现疑似数字、术语或结论矛盾时，定位原文并说明需确认处；仅作语言修改时保持原信息，不擅自更改定量结果或科学判断。

## 4. 学术语言与中英表达

围绕实际内容写具体、直接的学术语言。用有信息的对象、动作和比较替换空泛评价，删除重复开场、泛泛赞誉与没有推进论证的套话。精简以保留最短充分证据链为目标，篇幅按稿约和信息量安排，不设置统一压缩比例或硬性词数。

英文按学术英语的语序、搭配和信息组织重写，避免逐字移植中文句式；中文使用规范医学术语和连贯论证。术语、缩写、人称、时态、英美拼写、统计符号、图表编号和单位格式全文一致，按目标期刊要求处理。缩写首次定义，后续使用稳定；方法和结果的时态反映实际研究过程，已有知识与解释按语境表达。

检查冠词、单复数、主谓一致、修饰关系和指代，避免夸张修辞、口语填充、过量名词化或机械堆砌被动句。表达形式服务于清晰论证，不为显得正式而增加生僻词或冗长句。

## 5. 润色范围与交付

整篇论文的改写、仿写、润色或修改默认读取并使用 `word` Skill 的正式学术/论文版式生成完整 `.docx`；用户指定其他格式时按其要求。局部文本处理交付指定范围。排版和文件生成按本 Skill 的共同交付规范执行。

纯语言润色、精简或翻译依据现有稿件完成，无需为此开展新研究、补实验或强制建立文献 CSV。新增外部主张或纠正关键事实时，按共同证据规则定向核实。若问题涉及设计缺陷、结果可信度、关键证据不足或结论外推，交本 Skill 的审稿/实质改稿分支处理；在语言修改中保留事实，不用流畅表达补造内容。

交付可直接使用的修改稿；用户需要时附修改对照或少量关键说明。局部续改复用已定术语和风格，只核对受影响内容及其关联结论；发现新的实质差异时再扩大核对范围。不固定要求每句多个版本，也不因新增一轮修改重复启动整篇检查。

具体期刊要求以用户提供或实际读取的稿约为准。
