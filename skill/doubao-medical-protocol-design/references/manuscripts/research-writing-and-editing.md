# 科研写作、成稿与修改

用于选题指导、大纲、按大纲成稿、论文撰写、科研报告、语言润色、实质改稿和参考范文写作。按本次目标选择内容、深度和交付形式；研究方案设计作为独立部分，仅在本轮确需设计时衔接相应模块，不把设计队列、方案 manifest、统计、样本量或伦理设计作为所有写作任务的前置步骤。

具体审稿读取 `manuscript-peer-review.md`，实质改稿与审稿回复读取 `revision-and-reviewer-response.md`，语言润色读取 `manuscript-language-and-style.md`。本文件保留写作与素材的共同要求；各分支按用户目标组织，审稿报告、回复信、正式修改稿和整篇润色稿默认通过 `word` 交付，英文等非中文文档同样采用正式版式。

科研基金申请、改本子与基金评审意见进入 [基金分支](../funding/funding-workflow.md)；学位开题、一般科研报告和论文继续按本文件及方案设计分支处理。

## 1. 先确定本轮写作目标

读取用户问题、现有稿件、数据结果、大纲、参考范文及目标期刊要求，复用已有信息。目的和素材足以支持时直接继续；缺少偏好使用合理默认，真正影响事实或论证的缺口集中列出。

| 场景 | 本轮重点与可用产物 |
|---|---|
| 选题指导 | 从临床或学术问题形成候选方向，说明研究问题、价值、现有证据与可切入点，结合用户已有资源判断可行性；给出可继续使用的选题建议或论证提纲 |
| 提供大纲 | 按论文、报告或申报目的组织标题层级，为各节说明核心问题、论证要点、所需材料与证据；不只罗列通用章名 |
| 按大纲写作 | 沿用给定层级、主张和论证方向，逐节形成连贯正文，落实已有材料与引用；需要调整结构时说明对应位置，严格按纲的要求优先 |
| 完整论文 | 先区分原创研究与综述，按实际研究内容和目标期刊完成题名、摘要、正文、图表及参考文献 |
| 局部润色 | 在指定段落、章节或语言范围内改善术语、语法、逻辑衔接与学术表达，保持原意、数据和引用关系 |
| 实质改稿或审稿修改 | 对照用户要求、原稿或审稿意见，定位需要补强的论点、结构、证据和表述；修改正文，按需附简短修改说明或审稿回复 |
| 参考范文写作 | 提取范文的结构、论证节奏、语言风格和图表组织方式，以本题真实材料与证据重新成稿 |
| 科研报告 | 按开题、进展、阶段总结、结题或专题论证等用途，呈现目标、实际工作/方法、已有结果、问题与解释、结论及后续安排 |

医生提出选题或报告需求时，先形成可直接使用的指导、主线或提纲，再按本轮范围展开。用户要求正式报告或完整稿件时继续完成正文与 Word 文档，大纲作为成稿起点。

## 2. 素材、证据与论证

- **忠实于材料。** 研究对象、方法、样本、日期、数据、统计结果、图表和已完成工作以用户提供或实际核实的资料为准。尚未提供的结果保留待补位置，不把研究设想、计划或预期效果写成已完成研究及其发现。
- **分清证据与推断。** 原研究发现、用户数据结果和作者综合判断分别表达；解释适用范围、局限和替代解释，结论强度与证据相称。已有数据不足以支持的新结论先作为待核实问题，不通过润色直接改强。
- **按需核实外部主张。** 文献、指南和方法学依据按[相关研究与引用](../related-research-and-citations.md)及[工具路由](../tool-routing.md)检索、读取和核实。纯语言润色不强制扩展检索；需要补充事实或改变论证依据时，再核实相关来源。
- **参考范文。** 实际读取用户给定范文，学习其章节功能、论证组织、图表与表达风格；围绕本题材料原创组织内容，不照搬段落，不把范文的数据、研究经过或结论移植成本研究事实。采用其中具体观点或证据时引用实际来源。

## 3. 原创研究、综述和报告分别组织

### 原创研究论文

按真实研究类型和稿约组织题名、摘要与关键词、引言、方法、结果、讨论、结论及参考文献，按需设置图表和补充材料。方法准确反映实际执行，结果与现有数据和图表对应，讨论解释发现及其与既有证据的关系。定性、方法学或其他研究按其体裁调整，不机械套同一章节格式。

只有研究设想或方案、尚无实际结果时，可完成有依据的引言、方法草稿和可填结果框架；研究结果、效应量、显著性及结论不凭设想补写。

### 综述与主题论文

围绕明确问题组织背景、实际检索范围与方法说明、主题证据综合、讨论与局限、实践意义或展望、结论及参考文献。比较不同研究的一致性、差异、适用人群和方法限制，以论点串联来源。单篇摘要与阅读笔记用于写作素材。

叙述性、范围性、系统综述或 Meta 等体裁与实际完成的检索、筛选及分析方法相符；只有专题阅读和一般综合时，按真实范围命名和表述。

### 科研报告与选题论证

按用途选用背景与问题、目标、依据、实际工作或拟开展内容、结果与分析、困难及改进、结论与下一步计划。阶段报告明确截至时点；结题或成果报告区分完成成果与后续计划。选题论证重点说明问题价值、证据基础、切入点与现有条件，不自动扩成完整研究方案。

## 4. 修改深度与学术表达

局部润色保留研究含义、数值、单位、分组、结局、统计口径和引用指向；遇到歧义保留原意并标明需确认处。用户要求双语或英文润色时，统一术语、缩写、时态和学术用语，避免机械直译。

实质改稿围绕指定目标重组论证、补足必要证据、消除矛盾，并使摘要、正文、图表和结论一致。审稿修改可用“意见—修改位置—实际改动/回复”对应说明，篇幅按需要；只有实际完成的补充实验、重分析或数据更新才能写成已完成的修改。

已有目标期刊、栏目、稿约或模板时实际读取并落实文章类型、语言、篇幅、摘要、标题层级及图表要求，引文按下一节执行；未指定时采用正式医学学术论文写法。语言保持客观、准确、清晰，段落围绕论点展开，统一术语和缩写。

## 5. 引用、图表与正式 Word 交付

论文与科研报告在创建 Word 前明确引用默认采用现行 GB/T 7714 顺序编码制，按正文首次引用顺序编号，同一来源重复引用沿用同一编号；用户明确指定其他格式或制式时按其要求。具体著录与核实执行[相关研究与引用](../related-research-and-citations.md)。Word 正文 `[n]` 使用原生 run 上标，不附超链接；每条文末参考文献在国标条目后必须追加“（查看来源）”，其中“查看来源”为真实原始来源的超链接；已有 DOI 仍保留末尾入口。正文、图表和文末来源一一对应；题录、卷期、页码和 DOI 使用实际取得的信息。

图表围绕论文论点或报告问题选择，保留标题、编号、单位、图例、必要的方法说明和来源，正文有对应解释。用户已有数据图与表忠实保留；改图或重排不改变数据含义。

撰写、按大纲成稿、改写、仿写、润色或修改整篇论文，以及正式选题论证和科研报告，默认读取并调用 `word` Skill，以正式学术论文/科研文书模板或专业排版流程生成真正可打开的 `.docx`。即使用户未主动要求文件，也按整篇任务交付 Word；用户明确指定其他格式时按其要求。交接完整正文、标题层级、摘要关键词、图表与题注、国标引用编号及 URL 映射、目标稿约或模板，明确正文原生上标和每条末尾“查看来源”超链接要求，由 `word` 落实正式论文的专业版式、分页和文件生成。基金、作者单位、作者贡献、致谢等按用户实际信息和投稿要求填写。

Word 文末可按需要附简短、小字号浅灰字的使用说明、注意事项或补充阅读；较详细的修改说明、材料填写指引和拓展资料，可同步使用 `lark-doc` 创建配套飞书文档，具体见 `../output-and-feishu-qa.md`。简要核对内容范围、数据和引用对应后，使用 `present_files` 交付最终文件及已创建的配套文档链接。保留用户仅本地、禁止上传等偏好；局部文字修改按用户指定范围交付，不额外扩写整篇论文。
