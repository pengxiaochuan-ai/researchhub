# 临床干预研究设计

## 适配性

当主要问题是主动分配干预策略的效果、安全性、非劣效性、剂量、时机或实施方式时优先考虑干预研究。不能随机时，说明伦理、可行性或污染原因，并区分非随机干预与观察性暴露研究。

## 一、选择试验结构

| 结构 | 适用条件 | 关键风险 |
|---|---|---|
| 个体平行随机 | 干预可在个体层分配 | 失访、交叉、盲法 |
| 集群随机 | 干预作用于科室/机构或污染明显 | 集群数、ICC、招募偏倚 |
| 交叉试验 | 状态稳定、效应可逆、有洗脱期 | carryover、周期效应 |
| 析因设计 | 多个干预可独立/交互研究 | 交互、依从性和解释复杂 |
| 务实试验 | 关注真实诊疗条件下策略效果 | 干预异质、数据捕获、实施忠实度 |
| 非劣效/等效 | 保留既有获益且新方案有明确优势 | assay sensitivity、历史可迁移性、界值依据、依从性、ITT/PP 一致性 |
| 先导/可行性 | 重点是招募、流程、依从和参数 | 不应以疗效显著性作为成功标准 |

平台、自适应、阶梯楔形、N-of-1 等设计只有在问题和运营条件匹配时使用，并补充专门统计与治理审查。

## 二、最小方案要素

- 目标人群、场景、招募途径和资格；
- 干预、对照、剂量/强度、持续时间、允许/禁止合并治疗；
- 随机单位、序列生成、分配隐藏、分层/区组及实施角色；
- 盲法对象、盲态维护、紧急揭盲；无法盲法时的客观终点和盲态评估；
- 主要/次要终点、评估者、时间窗和确认规则；
- intercurrent events、依从、交叉、救援治疗和停药；
- 随访、退出、失访、数据截止和安全报告；
- 主要 estimand、分析人群、样本量和敏感性分析；
- 监查、数据管理、统计盲态、注册和报告。

## 三、干预与对照描述

使另一中心可以复制：内容、提供者、场所、频率、剂量、个体化规则、依从测量、允许调整和干预忠实度。药品/器械研究需核对说明书、监管状态和风险；超说明书或研究性使用要清楚标记，不自行判断合规。

对照可以是安慰剂、常规治疗、主动对照、等待名单或另一策略。说明为何符合伦理和临床问题；“常规治疗”需要定义允许范围和污染监测。

## 四、随机化与偏倚控制

- 序列生成、分配隐藏和实施分工分开描述。
- 招募发生在随机之前还是之后会影响选择偏倚，集群试验尤其需要说明。
- 分层因素数量与样本量匹配；中心效应和随机化因素进入分析规划。
- 开放标签时加强盲态终点评估、客观测量、标准化共干预和结局确认。
- 不根据分配后的变量随意排除受试者。

## 五、estimand 与分析人群

明确治疗策略、目标人群、结局变量、群体汇总和 intercurrent event 策略。ITT 是常见原则，但不能替代具体 estimand。非劣效试验通常需要 ITT 与 PP 的一致性解释；缺失、依从和救援治疗通过预设敏感性分析处理。

### 非劣效/等效的额外门槛

- 证明历史研究中主动对照相对安慰/无治疗的效应可重复，且当前人群、终点、剂量、依从、共干预和分析与历史证据具有可迁移性（constancy）；
- 论证当前试验能够检测到有效治疗差异（assay sensitivity），不能依靠两组都执行不佳得到“相近”；
- 从历史主动对照效应及其不确定性构建 M1，再根据必须保留的临床获益/比例构建 M2 或最终非劣界值；不以方便招募为界值依据；
- 在方案中预设界值尺度、方向、单/双侧显著性、ITT/PP 解释、缺失/交叉敏感性和结论规则；
- 若历史证据不足、终点/人群变化过大或 assay sensitivity 不可信，拒绝确证性非劣效定位，可改为优效性、可行性或描述性研究。

## 六、安全与监测

定义 AE/SAE、预期性与相关性、收集窗口、升级路径、暂停/终止规则、紧急医疗和独立监测需求。风险应与干预和人群相称；不是所有低风险研究都需要独立 DSMB，也不是高风险试验只写“必要时监测”即可。

安全方案必须区分三层：已经观察到的风险信号、法规/指南原文明确要求、研究团队拟议的风险控制。只有官方文件确实给出数值阈值或强制动作时，才可写成监管要求；原则性风险管理语言不能改写成固定暂停、终止或入排阈值。研究者提出的数值规则需明确标为“建议草案”，交代事件分母、严重度/相关性、机制、人群、既往阶段信号、获益风险和 IDMC/监管沟通触发条件。

肺功能、实验室、影像、剂量调整和监测频率等阈值应与具体适应证、作用机制、目标人群、产品版本及前期数据相匹配；不得把相邻药物类别、另一试验或另一疾病的规则无条件移植为本研究标准。依据不足时给条件化方案和待确认参数，不制造唯一“正确阈值”。

## 七、最低交付

试验概要表、流程/访视表、干预与对照、随机/盲法、终点、estimand、样本量场景、分析人群、安全治理、可行性和待确认的其他问题。正式稿按当前 SPIRIT 及适用扩展规划，并为最终结果报告映射当前 CONSORT 及适用扩展。
