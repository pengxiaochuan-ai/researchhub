# 终点、Estimand、样本量与分析框架

## 一、从目标到可分析声明

链条保持一致：

`研究目标 → 目标参数/estimand → 主要终点 → 时间窗与确认 → 分析单位/人群 → 统计方法 → 样本量依据`

任何一处改变都要检查下游影响。不能先按方便计算确定 N，再反向选择主要终点。

## 二、终点定义表

每个主要/关键次要终点记录：

| 要素 | 内容 |
|---|---|
| 概念 | 真正要衡量的临床、实施或实验现象 |
| 操作定义 | 事件/数值/量表的明确规则 |
| 来源 | CRF、EHR、登记、检测、阅片或算法 |
| 起点与时间窗 | 相对随机、入组、暴露、采样或实验处理 |
| 确认 | 评估者、盲法、裁决、重复/复核 |
| 不确定结果 | 缺失、无法判定、检测失败的处理 |
| 尺度 | 连续、二分类、计数、时间至事件、纵向等 |
| 解释 | 最小重要差异、阈值或绝对/相对效应 |

复合终点需说明组成部分的临床重要性、频率、方向和竞争关系；不为增加事件数拼接异质结局。替代终点或生物标志物需说明验证状态，不能自证临床获益。

## 三、试验 estimand

临床试验说明治疗、目标人群、结局、群体汇总和 intercurrent event 策略。死亡、停药、救援治疗、治疗转换、依从性和缺失不能只写成“按 ITT 处理”；其与科学问题的关系需明确。

观察性研究同样需写目标参数：目标人群、暴露/策略对比、结局和时间范围。预测研究写预测时点、范围和性能目标；诊断研究写目标场景、阈值和误判后果；实验研究写独立单位上的主要效应。

## 四、样本量规划立场

先选择一种立场：

- 正式效能估算；
- 置信区间/精度驱动；
- 所需事件数驱动；
- 固定可行 N 的可解释性评估；
- 先导/可行性目标；
- 模型开发/验证所需样本；
- 实验单位与重复结构规划。

核心输入包括主要目标、设计/分配、效应或精度、对照率/方差/事件率、显著性和效能、失访/失败、聚类/重复、非依从、多重性和可行上限。每个输入标为：本地已知、外部证据、有条件估计、猜测或缺失。

## 五、情景而非虚假精度

默认给基准、保守和可行性受限情景；必要时加乐观情景但不得作为唯一推荐。说明效应、事件率、方差、ICC、失访或可评价率变化如何影响 N/事件数。

- 生存研究区分事件数与入组人数；
- 聚类研究同时考虑集群数、每集群人数、ICC 和集群失访；
- 非劣效/等效研究给界值的临床和证据依据；
- 预测模型不用固定 EPV 口诀替代现代参数复杂度、结局频率、预期性能和 shrinkage；
- 诊断研究围绕灵敏度/特异度或目标区间及目标状态例数；
- 转化/实验研究以独立患者、供者或实验单位规划，不以特征/孔/细胞数冒充。

缺少关键参数时，给计算框架、需要补充的参数和先导方案，不编造单一 N。正式数值需使用可审计的软件/代码并保存版本、公式、参数和输出。

### 小样本事件率向未来样本外推

当用户用较小样本中的 AE、SAE、死亡或其他二分类事件率推演未来研究时，先还原并写明原始整数事件数 `x/n`；若只给百分比且无法唯一还原，不静默假定事件数。

- **原始率不确定性**：用明确命名的方法（如 Wilson 或 Clopper–Pearson）计算 `x/n` 的区间，并说明方法选择；不得对非整数“期望事件数”直接套用二项精确区间。
- **未来期望事件数**：点估计为 `N × x/n`。把原始率区间乘以未来样本量 `N`，得到的是由率估计不确定性传导出的“期望事件数范围”，不是未来实际观察事件数的预测区间。
- **未来观察事件数**：若用户要求预测未来会观察到多少例，另行给预测分布并写明模型。固定率的二项分布只包含未来抽样波动；要同时反映原始率不确定性，可用有明确先验与假设的 Beta-binomial/后验预测或相称的频率学方法，不能与上一步混称。
- 摘要、正文、表格和安全规则中的点估计、区间、分母与方法保持一致；检查点估计是否落在区间内，并保留可复算代码、软件版本和输出。

## 六、分析框架最低内容

- 主要分析人群/单位；
- 主要模型、效应尺度和区间；
- 设计因素、配对/聚类/重复结构；
- 协变量角色和主要调整集；
- 缺失、删失、竞争事件或检测失败；
- 多重性、亚组和探索标签；
- 模型诊断和关键敏感性分析；
- 中期分析/停止规则（如适用）；
- 软件、版本、盲态和复现要求。

方案阶段可以是统计框架；涉及确证性试验、复杂自适应、多重终点或监管提交时，必须安排生物统计师完成正式 SAP。
