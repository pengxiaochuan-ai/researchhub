# 人源样本强制叠加层

## 何时加载

任何研究使用可链接到人的组织、血液、体液、DNA/RNA、原代细胞、病理材料或其他人源样本时加载。它可以叠加在临床队列、诊断/预测、转化研究或实验生物医学之上，不改变主设计名称。

## 一、分开四种资格与人群

1. **参与者/供者资格**：谁可以进入研究或提供材料；
2. **标本资格**：采样时间、类型、体积/组织量、处理、保存和质量是否合格；
3. **检测可评价集**：检测成功、QC、批次和算法锁定后哪些样本可分析；
4. **最终分析人群/单位**：按预设规则保留的患者、供者或实验单位。

不得因标本质量失败静默把参与者从临床分析中删除，也不得把 aliquot、孔、细胞或切片数量写成供者/患者样本量。

## 二、样本链与元数据

至少定义：

`participant/donor → visit/timepoint → specimen → aliquot → storage/transfer → assay batch/run → output`

记录采样相对疾病、手术、治疗或结局的时间；部位、采集方式、处理延迟/冷缺血、抗凝/固定、离心/分装、温度、冻融、运输、存储位置、剩余量、操作人和时间戳。链接键去标识化、权限受控并可审计。

## 三、同意、授权与撤回

核对原始同意/豁免、二次使用、遗传分析、未来未指定研究、跨机构/跨境、商业使用、数据链接、结果返还和样本再使用。说明撤回后未使用样本、已生成数据、已共享数据和已发表结果如何处理；不能自行承诺超出机构政策的“完全删除”。

生物样本库/历史样本还需核对治理委员会、材料/数据转移、访问审批和保存/销毁。赫尔辛基/台北宣言、BRISQ、ISO 20387 和机构 SOP 提供不同层次的伦理、报告与能力要求，不能相互替代。

## 四、前分析、批次与盲法

- 病例/对照、结局组、中心和时间在采集、处理、保存及检测批次上尽量可比；
- 随机/平衡上板，设置参考材料、桥接样本和适当 QC；
- 检测人员和算法分析尽量盲于结局/组别；
- 预设质量阈值、失败、重测、剩余样本优先级和样本耗竭处理；
- 完全批次—组别混淆视为设计失败风险，不能声称后续批次校正完全解决。

## 五、结果返还和偶然发现

研究级 assay 默认不等于临床可报告检测。若计划返还个体结果，需说明分析/临床验证、实验室资质、确认检测、解释责任、可行动性、遗传咨询、同意选择和紧急路径。无上述条件时明确不返还或按伦理批准方案处理。

## 六、最低产物

- 四类资格/分析集表；
- 样本采集处理 SOP 要点与时间窗；
- 患者—样本—检测链和访问权限；
- 随机上板/批次/QC/盲法计划；
- 失败、重测、耗竭和撤回规则；
- 同意、共享、返还、保存和销毁治理；
- 样本流、偏离日志和最终可评价集定义。
