# 观察性与真实世界研究设计

## 一、先选能支持目标参数的设计

| 目标 | 常见设计 | 不能自动支持 |
|---|---|---|
| 暴露后结局发生/预后 | 前瞻或回顾队列 | 无条件因果、未测量混杂消失 |
| 罕见结局/长潜伏期 | 病例对照、嵌套病例对照 | 发病率、绝对风险（无额外信息时） |
| 某时点负担/相关 | 横断面、调查 | 时间先后和发病风险 |
| 常规诊疗中的治疗比较 | RWE 队列、目标试验模拟 | 等同随机试验 |
| 自然史/疾病轨迹 | 纵向队列、登记 | 无失访偏倚的完整轨迹 |

“回顾性”只描述资料时间，不是独立设计家族。病历回顾可以是队列、病例对照、横断面或描述研究。

## 二、队列

明确目标人群、源人群、资格、入组方式、time zero、基线窗口、暴露/比较、结局、随访、删失、竞争事件和分析单位。基线变量必须在 time zero 前可测；基线后变量不能随意进入混杂调整集。

前瞻队列适合标准化采集和未来结局；回顾队列适合已累积数据，但需评估测量目的、捕获完整性和数据截断。选择由问题与可测性决定，不以“更高级”为依据。

## 三、病例对照

- 定义隐含源人群、病例发生窗口和病例确认；
- 对照应代表源人群中可成为病例者，并说明抽样方式；
- 暴露窗口与病例发生前时间对齐；
- 评估回忆、选择、幸存者、错分和过度匹配；
- 匹配有明确理由，并与条件分析一致；
- 不能把病后生物标志物无条件解释为病因暴露。

若目标是诊断区分而非病因，转诊断准确性设计，不用“病例对照”标签掩盖两门诊人群的谱偏倚。

短暂暴露与急性、可明确起病时间的结局可评估 case-crossover；人内变化的疫苗/药物安全问题可评估 self-controlled case series。两者依赖事件时间、暴露时间、时间变化混杂和事件对后续暴露的影响，不能作为病例对照的机械替代。

## 四、横断面与调查

定义抽样框、时点、患病/状态定义、权重、非应答和测量工具。复杂抽样需在设计和分析中保留分层/整群/权重。横断面暴露—结局关联默认不支持时间顺序。

## 五、RWE 数据源

数据源选择围绕变量捕获：

- EHR：临床细节较多，但诊疗外事件、失访和记录目的带来缺口；
- claims：利用、处方/收费和大样本较强，但临床严重度和实际服药有限；
- registry：疾病/器械定义较专门，但覆盖与外部事件依赖具体登记；
- 链接数据：可补结局或暴露，但需要合法链接、链接质量和选择评估。

不得假设数据库含死亡、实验室、药品依从、疾病严重度或经过验证的表型。列出“已确认可得 / 可能可得 / 当前不支持”。

## 六、目标试验模拟

因果比较问题可把方案写成目标试验要素：资格、策略、分配近似、time zero、随访、结局、estimand 和分析。优先新使用者、主动对照和统一 time zero；处理宽限期、策略变化、依从和删失。

### 时间对齐是硬门槛

任何治疗比较都必须在同一 time zero 对齐资格判定、治疗策略分配（或与多个策略兼容的克隆创建）和随访开始。先写清在该时点实际可见的是医嘱、处方、配药还是实际服药；四者不能互相替代。

time zero 按可用数据精度定义到同一时间戳；不得写“出院日分组、次日开始随访”。若数据只有日期而没有日内时间，预先定义同日处方与同日结局的顺序、零时长事件和离散时间处理规则，并做替代顺序敏感性分析。

不得用 time zero 后的处方、配药或用药信息回溯定义基线固定组，再排除或忽略宽限期内死亡、MACE 等结局。常规倾向评分、回归调整、把治疗组随访起点移到首次处方，或简单删除早期事件，都不能修复这种不朽时间与选择/幸存者偏倚。

优先方案是按 time zero 当时可判定的治疗决策或处方策略分组，从 time zero 起纳入全部结局。此时 estimand 描述的是基线治疗策略，不得改称“未来一段时间实际启动或依从”的效应。若要估计持续依从某策略的 per-protocol 效应，预先定义动态策略和偏离时点，并用 CCW 或合适的 g-method 处理人工删失与受既往治疗影响的时间变化混杂。简单排除停药、换药或不依从者，或按后续实际治疗粗略分组，不能作因果性 per-protocol 解释；至多作为明确偏倚局限的描述性敏感性分析。

若研究问题必须允许启动宽限期，只能在数据与建模能力支持时选择并预先写明以下路线之一：

- **Clone-censor-weight（CCW）**：在 time zero 将每名合格者克隆到所有当时兼容的策略；从 time zero 起保留宽限期内全部结局；观察轨迹偏离某策略时人工删失该克隆，并用基线及必要的时间变化协变量估计人工删失逆概率权重。按原始个体处理相关性，明确 positivity、consistency、序贯交换性、权重模型与极端权重诊断。estimand 是从 time zero 起分配并遵循含宽限期策略的 per-protocol 效应。
- **Landmark**：把资格复核、分组和新的 time zero 一并移到 landmark；只纳入届时仍存活、未发生目标事件且可观察者，结局从 landmark 后开始。estimand 仅适用于达到 landmark 的条件人群，不能声称代表全部基线患者从原始起点开始的总效应。
- **时间变化暴露**：治疗前人时归相应未暴露状态，启动后更新暴露；若时间变化混杂受既往治疗影响，评估边际结构模型与相应权重。该 estimand 不等同于基线治疗策略效应。

只有未来首次配药数据而没有 time zero 的医嘱/处方时，不得假装基线策略已知。若 CCW、landmark 或时间变化方法都无法可靠实现，应改为描述性/关联性目标并明确剩余偏倚。

说明不可模拟的随机化、盲法和未测量信息。仅有纵向数据不等于已完成 target trial emulation；若 time zero、策略或结局不可构建，拒绝因果包装。

逐项登记识别假设：条件交换性、positivity、干预/策略定义的一致性、无干扰或其合理扩展、结局/删失的可识别性及模型正确设定。对每项写数据如何支持、可做的诊断/敏感性检查、不可检验部分和违反后应降级为关联性解释的条件。

## 七、偏倚与可行性矩阵

至少评估：选择、适应症混杂、不朽时间、检测/监测、逆向因果、暴露与结局错分、信息性删失、缺失、数据链接、中心变化和历年编码漂移。每项写“如何产生—影响哪一方向—设计阶段缓解—分析阶段检查—剩余限制”。涉及治疗启动宽限期时，另列资格判定、策略分配/克隆、time zero、随访起点、早期结局和 estimand 的对齐检查。

治疗比较的基线混杂域不能只写当前疾病严重度。至少逐项判断并记录：人口学与社会因素、疾病类型/严重度和关键实验室指标、既往结局、time zero 前的既往治疗史、入院前剂量和院内治疗轨迹、既往合并用药、共病、医疗利用与随访强度、就医可及性、医生/中心偏好、中心和日历时间。索引时点新分配的治疗或剂量属于暴露；同期新开的合并用药先判断是共同干预、策略组成还是中介，只有明确发生于策略分配前且是暴露与结局的共同原因时才考虑调整，不自动放入基线混杂集。只纳入 time zero 前且由因果结构支持的变量；不要按单变量显著性筛选。不可获得的既往治疗或医疗利用信息要进入数据缺口和残余混杂说明，并预设可行的负对照、定量偏倚分析、E-value、不同调整集或限制性分析，而不是默认倾向评分已解决。

## 八、最低交付

设计适配、目标/源人群、time zero、资格、暴露/对照、结局、随访/删失、变量与因果角色、偏倚矩阵、样本量/可行性、主要分析和敏感性分析、数据缺口及报告规范。观察性研究按当前 STROBE；常规医疗数据研究按适用的 RECORD 扩展规划。
