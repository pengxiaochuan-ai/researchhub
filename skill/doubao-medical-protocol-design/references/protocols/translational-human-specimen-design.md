# 人源样本转化研究设计

## 定位

转化研究以患者/受试者为临床锚点，以研究性组织、血液、组学、功能检测，或研究级影像采集/影像组学/跨模态特征为测量层。常规临床影像作为诊断/预测输入时默认属于临床模块；只有测量链和转化验证本身是核心问题时才走本分支。它不是“把临床队列加几项实验”，也不是“把细胞实验换成人体样本”。必须同时设计临床问题、测量链、检测质量和验证层级。

## 一、标志物用途

先选择一个主要用途：诊断、预后、预测治疗反应、药效/药代、监测、替代终点、患者分层、机制探索或技术验证。用途决定入组谱、采样时点、对照、终点、阈值和验证设计。

探索发现与临床验证分开。若样本只在结局后取得，不把测量无条件解释为病前暴露；治疗后样本可以是药效或机制标志，但需相应目标。

## 二、双层设计总结

### 患者层

疾病/场景、目标与源人群、入排、治疗路径、临床 time zero、主要结局、随访、混杂和可用临床数据。

临床终点必须与疾病阶段和治疗场景匹配。根治性手术后、无疾病证据的辅助治疗人群，通常优先定义 DFS/RFS、复发或死亡等终点；不要默认写 PFS、ORR 或 RECIST 反应。ORR/RECIST 反应终点要求有可测量病灶；PFS 主要用于仍有活动性疾病且能预先定义进展判定的场景，不把“存在可测量病灶”当作 PFS 的普遍必要条件。若场景尚未确定，列为 A 级未决项并给两套条件方案，不把两类人群混在同一主要 estimand 中。

仅在同一治疗背景下比较 assay 敏感/耐药者的 DFS/RFS，只能支持预后或治疗背景下的关联，不能据此声称“预测治疗获益”。若目标为预测性标志物，逐患者对齐体外检测药物/组合与实际接受方案、起始时间、剂量强度和方案变更，并预设 assay×treatment 交互或匹配/不匹配策略；单药读数映射 FOLFOX、CAPOX 等联合方案时先锁定组合算法。有合理治疗对照与预设交互或匹配分析时，可定位为探索性预测研究并明确“尚未独立验证”；确证性、可推广的预测声明才要求独立验证。没有有效治疗对照或交互/匹配分析时，降级为预后/关联性表述；临床效用另需 assay-guided 与标准策略的影响研究。

观察性标志物/转化队列不用 ITT、PP 命名分析集。分别定义 enrolled、specimen-available、assay-evaluable 和 clinical-evaluable 人群，报告建系失败、污染、检测失败和失访造成的选择机制；不能把未建系或未检测到的药敏当作可插补的普通连续缺失值，也不能默认多重插补出未观测药敏。

### 样本层

标本类型、部位、采样相对时间、采集管/固定、处理延迟、保存、冻融、aliquot、检测平台、批次/板位、操作者、失败规则和剩余样本治理。

提供稳定链接：`participant → visit/timepoint → specimen → aliquot → assay run → output`。定义去标识化、权限、追踪和链接失败处理。

## 三、样本来源与选择

- 连续/代表性入组优于只选“典型病例”；
- 既有生物样本库需说明原始同意、采集目的、可用性和选择机制；
- 病例/对照样本在采集、保存、处理和批次上尽量可比；
- 训练、验证和复现样本按患者分离；
- 样本耗竭、质量失败和不完整配对进入样本流与可行性。

## 四、批次与盲法

病例/对照、结局组、中心和时间不能与板/批次完全重合。规划随机上板、平衡阻断、重复 QC 样本、参考材料、技术重复策略和盲态检测/分析。批次校正不是替代良好上板设计。

## 五、验证阶梯

1. 技术/分析性能：精密度、重复性、稳定性、检测限、干扰等；
2. 发现与内部确认：锁定候选、阈值或模型，控制高维选择偏倚；
3. 独立临床验证：目标人群和预设分析；
4. 临床效用：是否改善决策或结局。

在方案中写明当前研究处于哪一级以及不支持哪一级声明。样本量以患者/独立供者和主要目标规划，不以基因、细胞或技术孔数量代替。

## 六、伦理与回报

说明知情同意范围、二次使用、遗传信息、偶然发现、结果返还、跨境/共享、样本销毁/再使用和撤回后的处理。不得默认研究级检测可返还为临床结果；需要经验证的检测、解释和治理路径。

## 七、最低交付

临床问题、标志物角色、患者层方案、样本流程、前分析和批次计划、检测与失败规则、统计/高维计划、验证路径、样本量情景、伦理治理、可行性和临床声明边界。
