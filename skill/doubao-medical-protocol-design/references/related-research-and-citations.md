# 相关研究、证据与引用

## 一、按科研任务确定证据范围

本文件负责科研任务共用的来源核实、引用和题录记录。纯语言润色、翻译和既有材料重组复用输入与已有来源；拟新增医学判断、关键数值或动态事实时定向核验。聊天直接回答在相邻内容引用实际来源；多来源论文/科研报告写作、相应证据综合和循证研究方案使用下文六列 CSV。专利材料的特征来源与现有技术记录按 `patents/patent-drafting.md` 组织；纯专利任务沿用该轻量对应，不触发期刊匹配。

基金任务中需要综合多来源的立项依据和研究背景，沿用本文件的题录与引用规则；资助通知、申请模板和经费要求按 `funding/china-application-format.md` 读取，简单申报咨询或已有材料的格式整理复用现有来源。

完整方案设计按需要补充“相关研究调研”：梳理研究主题的国内外现状、代表性研究、适用指南/共识、主要争议和本研究依据。它同时呈现主题认识与设计依据，参数查证只是其中一部分。原有证据范围在方案分支继续使用：

- `user_material_only`：依据用户材料及已有来源整理，新增外部证据范围由用户要求决定。
- `targeted_verification`：围绕当前研究主题与设计需要定向核对代表性研究、指南或共识，足以支持本轮任务即停。
- `evidence_informed`：按研究需要覆盖主要方向、代表性原始研究和适用指南/共识，形成研究现状、分歧及依据。

独立的系统性领域调研、进展、里程碑或热点梳理按任务路由交医学文献检索 Skill；科研写作、方法和方案任务在本 Skill 内复用所需证据。共享工具分工与停止条件见 `tool-routing.md`。

## 二、方案设计中的相关研究范围

按研究语境确定需要了解的现状和依据：

- **临床与人群研究**：疾病负担、临床现状、治疗/暴露比较、国内外代表性队列或试验、指南/共识，以及人群、终点和结论的异同。
- **人源样本转化研究**：临床问题、标本队列与检测研究、技术性能和临床关联、适用报告规范，以及证据可支持的临床声明层级。
- **实验生物医学研究**：研究对象和机制、代表性模型与技术路线、主要发现、可重复性、实验规范与临床前结论的转化边界。

优先直接相关的原始研究、适用指南/共识、可靠系统综述/方法学研究，以及必要注册记录和测量工具文档。国内外覆盖服从主题和适用地区；某一侧证据不足时如实表达。临床应用优先核对最新适用的国家规范、中国指南和本土证据；全球机制或方法问题按直接相关性选择。

## 三、证据核实与来源入口

### 来源身份与实际支持

来源价值结合真实性、方法质量、适用性与时效性判断。关键来源和重要参数定向核对实际题名、标识符、期刊/机构、年份/版本及所用结论的支持位置，复用已完成的读取；相似题名、同一试验的二次分析及不同论文应区分。一般背景按任务需要使用已取得且可核验的内容。

可引用 PubMed、PMC、DOI 解析页、期刊官网、Semantic Scholar，以及工具返回的第三方存储/索引 PDF。保留实际返回的完整原始 URL；镜像可以直接引用，无需换主站。`aka.doubaocdn.com` 域名的内容可以引用，也可以展示。原始 PDF 或索引入口按其实际内容判断，不按承载域名排除；低质量宣传、无来源材料不作为关键医学结论或设计参数依据。已取得题录直接使用，卷号仅在用户要求时额外核对。

`seed_medical_search` 返回的指南、共识内容 URL 不能 fetch，按 `tool-routing.md` 细化查询取得条文和上下文，或读取 `general_search` 返回的对应页面/PDF。论文摘要可支持其实际报告的内容；关键设计、统计参数与医学判断取得足以解释结论的原文、表格、脚注及适用范围后使用。

### 医学与方法学核实

- 关键阈值、量表、范围、分期/分级和官方术语回到原始指南、共识、量表或验证研究核实版本、定义、单位、测量条件和用途。程度与推荐强度保留官方原词，英语等级保留原文。
- 研究结果同时核对人群/模型、入排标准、比较组、终点/效应定义、分子分母、时间窗、估计值及不确定性；区分绝对差、相对变化、百分点及统计学与临床意义。
- 分析区分证据、推断和建议，强度与研究设计、偏倚风险和可迁移性匹配。临床研究需结合时间变化、归因与人群分层；涉及病例只使用用户实际资料。
- 药品批准、说明书、注册招募状态和监管要求按核验截止日的正式资料确认。涉及临床应用时核对指南框架、适应证、剂量、禁忌、相互作用和相关安全要求；对材料中已存在的不合理用药说明具体问题及依据。
- 某研究的入排阈值、活检窗口、检测组合或访视频率是该人群、版本和时间窗下的做法，推广为通用标准需另有适当依据。机制或临床前发现按其模型范围解释。
- 事件率、效应量、非劣效界值、MCID 或诊断参数用于关键样本量计算前，核对全文/官方文档中的支持位置、人群、时间窗与不确定性；仅有摘要且无法确认参数定义或迁移性时，先采用精度、事件数或敏感性情景分析。立题背景证据与计算参数分别评价。

## 四、六列题录与期刊匹配

多来源论文/科研报告写作、相应证据综合与循证研究方案使用 UTF-8 BOM 的内部 `literature-log.csv`，表头固定为：

```csv
citation_number,original_title,journal_or_institution,year,url,journal_rank_2025
```

按去重纳入顺序分配稳定的 `citation_number`，同一来源在正文、图表和参考文献中复用。题名、期刊/机构、年份及完整原始 URL 来自实际结果，新行 `journal_rank_2025` 留空交脚本填写。类型、证据级别、发现、局限及参数用途从已核实内容用于正文或当前上下文，不为这些信息扩充 CSV 列。

新建时先 Read `assets/literature-log-template.csv`，已有文件每次批量写入前先 Read 当前内容，再 Write。只记录本轮实际采用的来源。纯润色和聊天回答在上下文维护来源—结论对应即可。

拟纳入文献整理后，一次批量匹配已采用期刊论文的级别：

```bash
node "<Skill 根目录>/scripts/match-journal-rank.js" --csv literature-log.csv --in-place
```

脚本自行读入再写入 CSV，已满足先 Read 再 Write；调用前无需额外 Read。它读取 `assets/journal-rank-index.json`，写回 `journal_rank_2025`，stdout JSON 的 `results` 与行对应，实际字段包括 `citation_number`、`journal_or_institution`、`url`、`journal_rank_2025`、`status`、`matchedJournal`（另有 `row`、`confidence`）。直接按编号和 URL 用于正文、图表及参考文献，无需另读 CSV 取分区；后续新增或替换需要匹配的期刊再按需执行。

- `exact`、`alias` 可采用；`fuzzy` 先确认 `matchedJournal`，核对状态在上下文或方案 manifest 中保留。
- 未匹配、匹配不唯一或非期刊来源，正文省略期刊级别；正式表格对应字段显示 `-`。即使机构名碰巧命中，也只对实际期刊论文展示级别。
- 索引或工具不可用时继续完成任务，内部保留实际状态。期刊分区/级别仅描述发表载体，证据等级、方法质量、偏倚风险与可迁移性独立评价。

### 方案 manifest 的按需映射

方案分支采用 `protocol-manifest.json` 时，把同一 CSV/来源记录映射到 `reference_register`，相关研究和文末参考文献复用同一组来源。`source_id` 可由 `citation_number` 稳定派生，`title` 对应 `original_title`，`source` 对应 `journal_or_institution`，`year`、`url`、`journal_rank_2025` 直接承接；展示顺序需要调整时用 `citation_order` 保留映射。

以下原有设计追溯信息按当前方案实际需要记录，无需另外检索或重建一份台账：

| 信息组 | 可用字段与用途 |
|---|---|
| 引用展示 | `anchor_text`、`aliases`、`citation_order`、`used_in_sections`：锚文本、明确简称、展示编号和实际采用位置 |
| 来源身份 | `source_type`、`publication_medium`、`identifier_type`、`identifier`、`resolved_title`：来源类型、稳定标识符及实际读取题名 |
| 核验范围 | `verification_status`、`verification_method`、`verified_at`、`access_level`、`support_locator`：实际核实方式、日期、全文/摘要/注册/官方文档范围与支持位置 |
| 期刊匹配 | `journal_rank_match_status`、`journal_rank_matched_title`、`journal_rank_confidence`：由 stdout 的 `status`、`matchedJournal`、`confidence` 映射；置信度只用于核对匹配 |
| 结论与参数 | `claim_support`、`population_scope`、`time_window`、`uncertainty`、`parameter_use`：实际支持的主张、适用范围、时间窗、区间及参数用途；背景与参数用途分开 |
| 设计决策 | `design_question_ids`、`decision_use`：本研究采用该来源所回答的问题及具体决策位置 |

上下文压缩优先精简叙述，完整原始 URL 及其来源、编号、结论和参数对应原样保留。

## 五、方案中的相关研究模块

完整方案的“相关研究调研”通常置于“背景、研究缺口与依据”之后，可按任务结构合并、拆分、重命名或重排；其他科研任务按其成稿目标组织：

1. **章节导语**：说明调研范围、检索截止时间，概括当前研究状态。
2. **国内外研究现状**：连续叙述研究发展、主要方向、当前结论和争议，交代适用的国内外证据。
3. **代表性研究**：按需用表格 `地区/范围｜研究｜期刊/机构｜年份｜期刊分区/级别（2025）｜人群或模型与设计｜主要发现｜局限｜对本研究的启示`；题名本身可点击。
4. **相关指南与专家共识**：发布机构或期刊、国家/地区、年份、核心内容、对方案的影响和适用范围；以期刊论文发表且可靠匹配时可展示期刊级别。
5. **对本研究的启示与依据**：综合已知事实、准备回答的问题，以及设计、人群、比较和终点的依据。研究空白在此形成研究理由，内部检索问题不机械写成章节。

来源仅限用户材料时，沿用已有资料与实际证据范围组织内容；未提供的研究、结果或指南不补造。

## 六、聊天与正式文档引用

聊天对 `seed_medical_search` 和 `general_search` 返回的内容积极使用 `<RichMediaReference>["真实来源URL"]</RichMediaReference>`，同处多个来源可放在一个真实 URL JSON 数组；组件放在所支持内容的标点之后，尤其句号之后。其他来源用完整题名或明确简称的超链接。

正式文档按载体保留引用与来源对应。专利权利要求与摘要、其技术交底或来源附录按 `patents/patent-drafting.md` 的专利引用体例组织。学术 Word 正文的 `[n]` 使用原生 run 上标，不附超链接；每条文末参考文献在国标条目末尾必须追加“（查看来源）”，其中“查看来源”为指向本条真实原始 URL 的 Word 超链接，已有 DOI 或其他链接也保留该末尾入口。原生排版要求在生成交接时按 `output-and-feishu-qa.md` 传递。飞书文档在相关句段旁用 `<a href="原始URL">[1]</a>` 等编号链接来源，按首次出现编号，同一来源复用编号；文末列对应题名、作者/机构/期刊和年份并保留可点击入口。PPT 在各页页脚标注对应来源的超链接，文末汇总参考文献。文献名、编号和原始 URL 在正文、图表、CSV 与参考文献中保持对应，每条引用只支持实际核实的主张。

论文、研究方案、科研报告等学术文档以“参考文献”收录实际采用的外部来源，默认按国标顺序编码制呈现规范著录条目。按首次引用顺序展示，同一来源重复使用同一编号；内部稳定编号与展示编号不同时保留映射。用户需要文献比较时，可在相关研究部分另设 `编号｜文献（题名可点击）｜期刊/机构｜年份｜期刊分区/级别（2025）｜类型｜本研究采用位置或用途` 证据表，缺失字段显示 `-`，保留已知内容与有意义的限制。

论文、研究方案/方案报告与科研报告的引用默认按现行 [GB/T 7714—2025](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C6CE52E55AC09B9C79A20AEA77CEDD14) 顺序编码制著录，创建 Word 前先明确该默认格式，按正文首次引用顺序编号，同一来源重复引用沿用同一编号，并保留内部编号与展示编号映射。用户明确指定其他版本、制式或引用格式时按其要求。稿件结构和排版结合目标期刊/文种落实；Word 每条文献均保留末尾括号内“查看来源”的真实超链接，原始 URL 在来源记录与引文映射中保留，不为统一格式改换来源。

交付前简要确认主张、文献题名、编号和来源链接对应。触发 Word 生成时传递正文原生上标且不附超链接，以及每条参考文献末尾“查看来源”超链接要求；在线文档按实际需要回读。来源记录、CSV 和其他过程材料保留在任务内部。
