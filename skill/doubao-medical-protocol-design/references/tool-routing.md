# 科研任务工具路由

先确定本轮科研任务、需要解决的问题和最终产物，再选择工具。方案设计、研究方法、数据解释、论文写作和材料润色共用以下能力；设计与计算的完整链路按任务需要展开。

## 一、按需调用

纯材料整理、翻译或语言润色复用用户材料和已有来源；新增医学断言、关键数值、研究状态或设计依据时，围绕该内容定向核验。多来源论文/科研报告写作、相应证据综合与循证研究方案使用 `related-research-and-citations.md` 的六列 CSV；普通聊天和纯润色在上下文维护来源对应即可。专利分支按 `patents/patent-drafting.md` 检索专利现有技术并保留特征与来源定位；纯专利材料按其文种处理来源，期刊匹配用于相应学术证据任务。

| 任务 | 优先能力 | 产物/记录 |
|---|---|---|
| 读取现有稿件、方案、CRF、表格和附件 | 文件/文档/表格读取能力 | 实际内容、版本与可读范围 |
| 科研基金申报指南、年度要求、申请模板与经费规则 | 直接调用 `general_search` 定位资助机构官网并读取正文和附件，无需 `tool_search`；用户已提供的当年模板优先复用 | 机构、年度、类别、实际标题/字段、篇幅与经费方式；具体按 `funding/china-application-format.md` |
| 指南、共识与国家规范 | 直接调用 `seed_medical_search`，每次 Query 包含 `filetype:guideline`，无需 `tool_search`；先最新中国指南/本土共识，再补国际权威指南 | 发布机构、年份/版本、适用人群及推荐条文 |
| 药品说明书、剂量、禁忌、特殊人群和监管标签 | 直接调用 `seed_medical_search`，每次 Query 包含 `filetype:drug`，无需 `tool_search` | 通用名、剂型/规格、企业或上市许可持有人、适用地区、版本和真实链接 |
| 学术论文、综述、试验与方法学 | 优先 `general_search`、`scholar_search`：general 直接调用；首次使用 scholar 前先 `tool_search` 发现并读取合同 | 相关原始研究、稳定标识符、完整原始 URL 与检索截止日 |
| 权威网页、期刊/DOI、注册与公开 PDF 入口 | 直接调用 `general_search`，无需 `tool_search` | 工具返回的原始入口及来源身份 |
| 较新论文题录补充 | 已安装且当前可用的 PubMed MCP，按实际可用接口直接、适度调用 | 发表/更新日期、人群、统计口径及发表状态相符的结果 |
| 相关图片 | 先 `tool_search` 发现 `visual_search` 并读取合同，再搜索图片 | 图片与实际来源信息 |
| 重要来源与关键参数 | 原文/网页/PDF 读取能力；seed 指南/共识按下节路径 | 支持结论的完整上下文、表格/章节位置和实际阅读范围 |
| 已采用期刊论文的期刊分区/级别 | `match-journal-rank.js --csv <literature-log.csv> --in-place` | 写回六列 CSV，stdout `results` 直接用于正文与参考文献 |
| 当前伦理、监管和注册 | 发布组织、监管机构、注册平台的正式记录 | 版本、法域、适用范围与实际状态 |
| 终点、量表、编码和数据源 | 维护方手册、原始验证研究、数据字典 | 操作定义、许可、版本与捕获缺口 |
| 样本量和统计情景 | 可审计的 R/Python/统计软件 | 公式/函数、参数来源、版本与情景输出 |
| 独立数据统计表、汇总表、访视表、变量字典、样本/进度表或工作簿 | 读取并使用 `sheet` Skill 创建；无需用户明确写出 Excel/xlsx | 可独立编辑的表格、字段定义、公式及与正文的对应 |
| 论文、方案或报告中的正文表格 | 随 `word` 或对应文档能力制作 | 与正文一致的表题、字段、单位、数据与来源 |
| 流程、time zero、样本链 | 按载体选择可编辑流程图/白板 | 节点含义、时间关系与正文一致 |
| 正式科研文档与配套说明 | 正式材料默认调用 `word`；明确飞书/在线协作或适合配套补充材料时用 `lark-doc`，PPT 用 `ppt` | 完整正文、表格、来源和真实入口；Word 可附简短文末说明，也可同步交付飞书补充材料，见 `output-and-feishu-qa.md` |

## 二、检索与阅读

基金资助通知和申报格式先查对应资助机构的官方年度材料，使用上表的 `general_search` 路径；医学指南/说明书与研究论文仍按以下共同顺序处理，两类需求按其职责分别取用。

与医学文献检索 Skill 使用同一默认顺序，按本轮问题选取需要的步骤：

1. **指南/共识与说明书**：有相关核对需求时，先直接调用 `seed_medical_search`。指南优先最新中国指南、本土共识及国家/学会规范，再补国际权威指南；说明书核对药名、剂型、规格、企业/上市许可持有人、地区与版本。
2. **研究论文**：优先 `general_search`、`scholar_search`。general 直接用；scholar 首次使用前先 `tool_search`。两者属于同一优先阶段，相互独立的查询可同批并行，无需等一个工具全部搜完再用另一个。优先近 5 年直接相关论文，按问题覆盖综述、Meta、原始研究与方法学文献；经典方法和里程碑研究按价值保留。可用 PubMed MCP 仅适度补充较新论文题录。
3. **权威入口补充**：按需用 `general_search` 定位学会/监管官网、期刊与 DOI、注册记录和公开 PDF，复用已有可用入口。
4. **核心原文读取**：候选完成初筛与来源记录后，先对最能支撑本轮结论或参数的少量核心资料定向读取；普通任务通常先读 1–3 份，后续围绕实质缺口补充。seed 指南/共识按下方专用路径读取。

无指南/说明书需求时跳过第 1 步。用户只查指南/共识时，检索与引用限定在此范围，general 仅按需补充和核对官方入口；用户限定其他文献类型时同样执行。指定期刊、机构、学会或数据库时，先完整覆盖并突出指定范围，再为关键缺口少量补充其他来源。不同资料方向的独立查询尽量同步并行、批量发出并统一等待，有依赖的查询再接续。

具名工具确实不可用时，选用当前可用的同等能力，保留“指南/说明书 → 通用与学术论文 → 权威入口 → 核心原文”的职责顺序。已直接可用的 seed、general 直接调用，scholar 与 visual 的发现要求按上表执行。

指南/共识与说明书分别使用对应 `filetype`。`seed_medical_search` 返回的指南、共识内容 URL 不能 fetch；需要细节时，细化 Query，多次取得推荐条文和上下文，或用 `general_search` 找到对应内容，再 fetch 其实际返回的可读取页面或 PDF URL。

用户强调“最新/近期”时，涉及指南/共识仍先用带 `filetype:guideline` 的 `seed_medical_search`，随后适度前移 `general_search`，补充可能尚未被收录的指南更新、期刊在线发表、学会公告和监管信息，核对发布机构、日期与状态，并继续用 `scholar_search` 覆盖研究证据。若任务本身只是限定范围的近期医学资讯，先用 general 检索正式发布，再用 scholar 定位对应论文或既有证据。

关键医学结论、终点定义和重要参数定向核实来源身份、版本、人群及支持位置，取得足够上下文后使用。搜索片段不足时更换聚焦 Query，仅在工具支持时扩大 `snippet`、`max_length` 等参数。seed 指南/共识遵循上面的读取路径；其他核心指南、重要论文可定向读取相关原文、脚注或补充材料。一般性背景按相关程度处理，复用已完成的核验。

主张、重要限制及当前研究决策已有可靠支持时停止，首批足够即可结束；后续仅补可能改变结论、安全边界或关键参数的具体缺口。检索深度随任务简繁安排，文献数量服务于论证与设计。

来源入口、医学证据核实、原始 URL 保留、CSV 和引用呈现统一按 `related-research-and-citations.md`，避免重复建立来源记录。

## 三、方案设计中的注册与可行性

需要研究空白或竞争性判断时，检索 ClinicalTrials.gov、WHO ICTRP、ChiCTR 或领域登记，核对相关记录的状态、设计、主要终点、更新时间和结果链接。研究数量依据去重后的实际记录统计。

本地招募率、事件率、样本库存和字段可用性优先由机构实际数据核验。研究现状、立题依据和参数来源分别判断：某研究提示“可能有效”，其效应量是否适合作为本研究参数，还需结合人群、设计、结局定义、时间窗、估计值与不确定性评价。

## 四、方案设计与统计任务中的计算

主要目标、终点、比较、设计和关键参数明确后，选择适用的二分类、连续、生存、聚类、重复测量、非劣效、诊断或预测模型方法。保存可运行代码和完整输出；复杂设计或监管用途按需交统计师复核。

在线计算器可用于交叉检查，计算过程仍需可复算。只有固定可行 N 时，分析精度、可观察事件数或可解释性情景，并说明参数来源和情景含义。

## 五、工具使用与实际依据

- 受控患者数据、人源样本清单和未公开方案使用已获授权的处理环境。
- 按实际取得的附件、原文、工具结果和计算输出说明结论；来源阅读与计算状态据实保留。
- 临床方案、统计方法、实验路线及伦理材料形成可供相应专业团队续审的内容。
- 使用产物工具当前 schema，交接完整正文、表格和来源链接；在线文档按实际需要回读。
