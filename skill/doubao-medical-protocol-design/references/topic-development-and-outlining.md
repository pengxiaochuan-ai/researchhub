# 选题、研究思路与大纲

用于医生提供方向、题目、科研目的或拟写材料时，帮助形成能继续开展研究或写作的主线。按问题范围给指导，只有用户确实要设计研究时才进入完整方案分支。

## 1. 从主题形成可回答问题

先看临床/科学问题、用户已有资源、资料与使用目的。需要时用目标人群/系统、干预或暴露、比较、结局、时间和场景聚焦；基础、机制、定性等任务按本身的问题结构组织。

围绕以下内容给出实质建议：

- 这个问题为什么值得做，现有研究已经解决了什么，还存在哪个具体缺口。
- 本地可获得的数据、样本、随访、实验平台、协作和时间能支持什么层级的问题。
- 首选题目、核心研究问题或写作中心论点，以及一两个有差异的备选方向。
- 创新点的具体来源，如人群、测量、时机、方法、机制或实施场景；新颖性根据实际检索判断。
- 最先开展的一步，以及最可能改变方向的关键信息。

需要立题或新颖性论证时，检索与主题高度相关的近期综述、指南和关键原始研究，按 `tool-routing.md` 与 `related-research-and-citations.md` 保留来源。每个候选方向说明其证据基础、可行性和主要价值；已有材料中的研究事实与拟议内容分别表达。

## 2. 按最终材料生成大纲

| 材料 | 建议主线 |
|---|---|
| 原创研究论文 | 问题与目的 → 实际方法 → 实际结果 → 解释与比较 → 局限 → 结论 |
| 叙述性/专题综述 | 背景与范围 → 主题或机制分节 → 证据比较与争议 → 应用或研究展望 → 结论 |
| 系统综述/Meta | 明确问题 → 实际检索与纳排方法 → 筛选及合成结果 → 偏倚/异质性与解释 → 结论 |
| 开题/立项材料 | 背景与依据 → 科学问题与目标 → 研究内容与技术路线 → 设计/方法 → 创新与可行性 → 进度及预期成果 |
| 进展/结题报告 | 原定目标 → 实际实施与完成度 → 已取得结果 → 变更和问题 → 综合评价 → 后续计划或成果 |

大纲的层级、篇幅与章节按用户要求调整。需要可执行提纲时，每个主要小节写清本节论点、拟使用的材料/证据及衔接关系；用户仅需简短目录时直接给目录。参考用户提供的大纲时保持其主线，实质调整说明简要理由。

## 3. 从指导继续成稿

用户要求完整报告或论文时，以本轮确定的题目、结构和证据进入 `manuscripts/research-writing-and-editing.md`，再使用 `word` 生成正式文档。已有真实资料充分时直接成稿；研究尚未实施时可形成开题、研究计划或带待填位置的论文框架。正式论文中的研究结果、样本量、统计结果和结局使用实际资料。
